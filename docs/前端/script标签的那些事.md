# script标签的那些事

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/vardy1)

我们还是先通过几个问题来了解一部分知识吧

## 问题1

**为什么script标签一般放在body底部而不是head表标签内部?**

我们知道html文件时从上到下一次解析的，当遇到script标签的时候会对其中的js文件进行下载、解析和执行之后才能接着解析下面的内容，如果把该标签放在head标签中很明显会阻碍DOM树的构建，用户体验不好。

## 问题2

**如果script标签中使用scr引入了外部的js文件，同时在标签内部写了一些js代码，代码代码会如何执行?**

浏览器会忽略标签内部的js代码

  

## 延迟脚本async和defer

### defer（延迟脚本）

这个属性的用途是表明脚本在执行时不会影响页面的构造。也就是说，脚本会被延迟到整个页面都解析完毕后再运行。

原则上使用defer属性的js文件会在DOMContentLoaded事件前执行，但实际情况并不一定是这样；同时如果有多个defer脚本也不一定都是按顺序执行的（原则上是按顺序执行的）

## async(异步脚本)

和上面的defer很像，只不过异步脚本不能保证多个脚本的时候是按顺序执行的，因此确保两个js文件互不依赖很重要，另外异步脚本一定会在页面的 load 事件前执行，但可能会在 DOMContentLoaded 事件触发之前或之后执行。鉴于如此，所以不要在异步js文件中操作DOM
