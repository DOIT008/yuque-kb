有的时候，在不同组件之间进行动态切换是非常有用的，我们常常能想到的应用就是`tab`页，当然tab页可能不是太恰当，因为我们一般要求`tab`页的组件是有缓存的，这里只是来说明问题：

在Vue3中，可以通过 Vue 的 `<component>` 元素加一个特殊的 `is` attribute 来实现，例如：

## 代码示例

```vue
<!-- 组件会在 `currentTabComponent` 改变时改变 -->
<component :is="currentTabComponent"></component>
```

这里的`currentTabComponent`可以是如下的值：

-   已注册组件的名字（就是组件的`name`属性）
-   一个组件的选项对象(就是`import`过来的那个对象)

## 举个例子

### 两个组件

compo1.vue

```vue
<template>
  <div>{{ desc }}</div>
</template>

<script>
import { onMounted, reactive, toRefs } from "vue";

export default {
  name: "compo1",
  setup() {
    const state = reactive({
      desc: "这里是组件compo1",
    });
    // 只要切换到该组件都会执行，毕竟重新初始化了嘛
    onMounted(() => {
      console.log("欢迎来到组件compo1");
    });
    return {
      ...toRefs(state),
    };
  },
};
</script>

```

compo2.vue

```vue
<template>
  <div>{{ desc }}</div>
</template>

<script>
import { reactive, toRefs, onMounted } from "vue";

export default {
  name: "compo2",
  setup() {
    const state = reactive({
      desc: "这里是组件compo2",
    });
    // 和compo1一样
    onMounted(() => {
      console.log("欢迎来到组件compo2");
    });
    return {
      ...toRefs(state),
    };
  },
};
</script>
```

### 使用

```vue
// Father.vue
<template>
  <div>
    <button @click="handleSwitchCompo">切换组件</button>
    <component :is="currentCompo"></component>
  </div>
</template>

<script>
import compo1 from "/@/components/compo1.vue";
import compo2 from "/@/components/compo2.vue";
import { ref, computed, reactive, toRefs } from "vue";
export default {
  setup() {
    // 默认currentCompo是compo1,这里的compo1来自组件compo1的name属性
    const currentCompo = ref("compo1");
    const isTrue = ref(false);
    function handleSwitchCompo() {
      isTrue.value = !isTrue.value;
      // 根据isTrue改变currentCompo的值
      currentCompo.value = isTrue.value ? "compo2" : "compo1";
    }
    return {
      currentCompo,
      handleSwitchCompo,
    };
  },
  components: {
    Son,
    // 要先进行中注册，毕竟将来component渲染的还是真实的组件
    compo1,
    compo2,
  },
};
</script>

<style lang="scss" scoped></style>

```

### keep-alive

但是你会发现，上述切换会有问题——每次切换都会执行`onMounted`这个生命周期的钩子 ，有时候我们更希望把这些组件缓存起来，这就用到我们即将要讲的`keep-alive`组件，我们可以在`component`外套上`keep-alive`标签，比如：

```vue
<keep-alive>
	<component :is="currentCompo"></component>
</keep-alive>
```

关于`keep-alive`组件的其他属性可以看官网的文档，和Vue2.x的差不多，这里就不做过多赘述。

### 和router-view的火花

我们在使用`router-view`的时候，为了提升性能 ，在vue2.x的时候往往需要在`router-view`的外部添加一层`keep-alive`，来缓存已经渲染过的界面，以达到提高渲染速度的目的，例如：

```vue
<keep-alive>
	<router-view/>
</keep-alive>
```

但是在Vue3.x中，用法已经不是这样了，已经变成了这样：

```vue
  <router-view v-slot="{ Component }">
    <keep-alive>
      <component :is="Component" />
    </keep-alive>
  </router-view>
```

### keep-alive原理

`keep-alive`是一个通用组件，它内部定义了一个`map`，缓存创建过的组件实例，它返回的渲染函数内部会查找内嵌的`component`组件对应的`vnode`，如果找到了就返回它。由于`component`的`is`属性是一个响应式数据，因此只要它变化，`keep-alive`的`render`函数就会重新执行。
