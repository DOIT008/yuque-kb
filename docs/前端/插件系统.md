# 插件系统

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/zyshfs)

需要在项目的根目录下创建plugins文件夹（Nuxt3会自动读取plugins目录下的文件并加载他们），里面是一个个的JS文件，如果在文件名添加`.server`或者`.client`，表示的是该插件只会在服务端（客户端）生效：

## 一、定义一个插件

要定义一个插件，会使用到`defineNuxtPlugin`

一个常见的应用是给NuxtApp实例提供一些额外的帮助方法，我们可以通过编写一个插件返回一个对象，在里面设置`provide`key,比如：

## 代码示例

```ts
import { defineNuxtPlugin } from '#app'
export default defineNuxtPlugin((nuxtApp) => {
  return {
    provide: {
      hello: () => 'hello,world',
    },
  }
})

```

页面中使用

```vue
<script>
  // 自动添加$前缀，以示区分
  import {$hello} from 'useNuxtApp';
  console.log($hello())
</script>

```

## 二、定义Vue插件

如果想要扩展Vue，我们通常要访问Vue实例，引入Vue插件，在nuxt3中可以通过插件访问`nuxtApp.vueApp.use(xxx)`做到，下面我们试下`vue-devui`

安装UI库

```powershell
npm i vue-devui
```

定义插件

```ts
import { defineNuxtPlugin } from '#app';
import {button} from 'vue-devui';
import 'vue-devui/button/style.css';
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.vueApp.use(button)
})
```

在页面中使用

```vue
<n-button>按钮</n-button>
```
