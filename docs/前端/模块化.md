# 模块化

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/bcv9ya)

其实TS的模块化和ES6的模块化差不多，所以如果你比较熟悉ES的模块化的话，这个就是小菜一碟啦！

模块化无非要涉及到两个方面——导入和导出，现在做一下说明：

## 使用export

### 分别进行暴露

## 代码示例

```ts
// 14.ts
export let names: string[] = ["张三", "李四", "王五"];
export function getName(): void {
  console.log(names);
}

// 15.ts
import { names, getName } from "./14";
```

### 集中暴露

```ts
// 14.ts
let names: string[] = ["张三", "李四", "王五"];
function getName(): void {
  console.log(names);
}
export { names, getName };

// 15.ts
import { names, getName } from "./14"; //还是一样
```

## 使用export default

和`export`的区别是`export default`只能使用一次，还有就是引入方式不同，例如：

```ts
//14.ts
let names: string[] = ["张三", "李四", "王五"];
function getName(): void {
  console.log(names);
}
// 只能使用一次
export default { names, getName };//导出的是一个对象

// 15.ts
import testModule from "./14";
console.log(testModule.getName(), testModule.names); // [ '张三', '李四', '王五' ]
```
