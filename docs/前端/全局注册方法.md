# 全局注册方法

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/agf74q)

我们经常在Vue2.x中使用`Vue.prototype.$xxx = xxx`的方式来注册一些全局的方法，最常见的就是`Axios`：

## 代码示例

```js
import axios from 'axios';
Vue.prototype.$axios = axios;
```

但是在Vue3.x中就不能这么用了，官方更推荐的是使用provide/inject的方式，还是上面的例子：

在`src/common`文件夹下创建`symbol.ts`文件：

symbol.ts

```ts
export const AXIOS = Symbol("axios");
```

main.ts

```ts
import { createApp } from "vue";
import App from "./App.vue";
// 引入Symbol变量
import { AXIOS } from "./common/symbol";
import axios from "axios";

const app = createApp(App);
// 将变量axios抛出去
app.provide(AXIOS, axios);
// 或者使用字面量的形式
// app.provide('$axios',axios)

```

在某个`.vue`文件中，使用`provide`方法定义变量：

```vue
<script>
  //  还得引入变量
	import { AXIOS } from "../../../common/symbol";
  import { inject } from "vue";
  setup() {
    const $axios: object | undefined = inject(AXIOS);
    // const $axios: object | undefined = inject('$axios');
    return {
      
    };
  },
</script>
```
