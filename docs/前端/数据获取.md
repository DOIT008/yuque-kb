# 数据获取

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/gqt8uu)

Nuxt的数据获取，通常有四种方式：

1.  useAsyncData
2.  useLazyAsyncData
3.  useFetch
4.  useLazyFetch

## 一、useAsyncData

是一个函数，接受两个参数：

## 代码示例

```ts
const data = await useAsyncData(
  key,//是为了防止多重请求设置的必要的标记
 callback=>{},// callback是获取数据后的回调
 option?={lazy:boolean, // 是否在阻塞路由，直到数据请求过来之后，一般赋值false
          server:boolean // 是否在服务端请求数据，一般用在首屏渲染时，默认时true
         }
)
```

其中`key`，callback是获取数据后的l回调，option是一个对象里面有两个参数：

```vue
<template>
  <div class="todo">
    <ul>
      <li v-for="(item, index) in todoList" :key="index">{{ item.title }}</li>
    </ul>
  </div>
</template>

<script>
export default {
  name: 'todo',
  data() {
    return {
      todoList: [],
    }
  },
  methods: {
    async getData() {
      const data = await useAsyncData('todo1', (NuxtApp) => $fetch('/api/todo'))
      console.log(data)
    },
  },
  mounted() {
    this.getData()
  },
}
</script>

<style lang="scss" scoped></style>

```

## 二、useLazyAsyncData

基本上就等同于`useAsyncData`，只不过`lazy`是`true`

## 三、useFetch（推荐）

其实是useAsyncData的封装，自动生成key并且自动推断响应类型，用起来更简单，用法和useAsyncData基本上一样：

```ts
const data = await useFetch(url,option?={lazy:boolean, // 是否在阻塞路由，直到数据请求过来之后，一般赋值false
          server:boolean, // 是否在服务端请求数据，一般用在首屏渲染时，默认时true
          //  others                 
         })
```
