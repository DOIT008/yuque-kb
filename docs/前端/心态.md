# 心态

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/lgmdr3)

## 背景与思路

总是在纠结中浪费着时间——

\-到底要不要刷算法？

\-现在刷算法还来得及嘛，毕竟自己....

\-如果到头来自己忙来忙去，最后还是进不去大厂该怎么办？

说实话这是典型的焦虑，有这种焦虑其实很正常。毕竟谁也不愿意自己的付出得不到回报...，但是你要这样想：

即便是最坏的情况，自己依旧没能够进入大厂，我想这一段刷题的经历依然是一段宝贵的精神财富，虽然它没能给你最期望回报，但相信它能锻炼你厚重的人格，能锻炼你的自律精神！这也算是一种回报吧！

是的，刷题本来就是一件无聊，痛苦的事情，而且还浪费时间，你或许会想——用这些时间来刷刷剧，看看电影不香嘛？香，当然香！但是然后呢，它能给你留下什么？！除了一时间的短暂的愉悦还有什么呢？！但是刷题就不一样了，虽然过程痛苦，或许你会失去很多花前月下的时间、或许你会失去很多“快乐”，但相信这段历程在未来一定会成就不一样的你！因为至少磨砺了你的人格！至少你没浪费时间！至少你不后悔，至少你在为你的梦想踏踏实实的做些什么，这就足够了...
