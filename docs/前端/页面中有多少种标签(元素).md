# 页面中有多少种标签(元素)

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/sae4og)

## 背景与思路

最直接方法是使用ES6的new Set()：

## 代码示例

```js
Array.from(new Set(Array.from(document.getElementsByTagName("*")).map((item)=>item.tagName)))
```

可能不太好看，那就来个简单的，把上面的进行拆解：

```js
var allElements = document.getElementsByTagName("*");//获取页面上的全部元素，是一个类数组对象
var allElementsArr = Array.from(allElements).map(item=>item.tagName)//将其转为数组并抽离出其标签名
var filteredElementsArr  = Array.from(new Set(allElementsArr))//去重并将其转为真正的数组，因为使用new Set后返回的是一个iterator对象，不是数组

```
