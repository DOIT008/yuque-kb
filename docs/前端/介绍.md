## 一、什么是Nuxt3

一个通用的开发框架，能够提供良好的代码组织和其实可以用来做`SSR`渲染

## 二、使用

创建项目

## 代码示例

```powershell
yarn create nuxt-app <project-name>
```

> node 版本>=14.16.0，可以使用NVM管理你的node版本，亲测16.10.0可以

## 三、运行和打包

进入你的项目目录，运行：

```powershell
yarn dev
# npm
npm run dev

// 打包
yarn build
# npm
npm run build

```
