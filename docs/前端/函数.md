## 函数分类

### 无返回值

例如

## 代码示例

```ts
// name必须是字符串，age必须是数字类型，否则就会报错,后面的void表示该参数没有返回值
function descPerson(name: string, age: number): void {
  console.log(`大家好,我是${name},今年${age}岁了`);
}
descPerson("张三", 29); //大家好,我是张三,我今年29岁了
```

### 有返回值

就要在最后一个半括号`)`后面追加数据类型`...):type`，例如：

```ts
function descPerson(name: string, age: number): string {
  return `大家好,我是${name},今年${age}岁了`;
}

```

## 函数参数

### 可选参数

顾名思义，就是说函数的某个参数是可以不传的，通常在该参数后面加`?`来表示，例如，还是上面的例子：

```ts
// 可选参数age
function descPerson1(name: string, age?: number): void {
  console.log(`大家好,我是${name},今年${age}岁了`);
}

descPerson1("张三"); //大家好,我是张三,我今年undefined岁了，但不会报错
descPerson1("张三", 29); //大家好,我是张三,我今年29岁了
```

> 但是，可选参数必须是最后一个函数参数(配置到最后面)

### 默认参数

默认参数只在ES6和TS中支持，ES5不支持，其实就是某个参数有默认值，比如：

```ts
function descPerson2(name: string, age: number = 18): void {
  console.log(`大家好,我是${name},今年${age}岁了`);
}
descPerson1("张三"); //大家好,我是张三,我今年18岁了
descPerson1("张三", 29); //大家好,我是张三,我今年29岁了
```

### 剩余参数

其实这个是ES6中的语法,这个要用到“`...`”运算符，因为我们知道我们**传入函数的参数是一个类似数组的对象**，所以可以用`...`进行解构。

​  

```ts
// 全部解构,nums其实是一个数组
function getSum(...nums: number[]): number {
  console.log(nums)//传入的参数组成的数组
  return nums.reduce(function (pre, curr) {
    return pre + curr;
  }, 0);
}
console.log(getSum(1, 2, 3, 4, 5)); //15
console.log(getSum(1, 2, 3, 4, 5, 6)); //21
```

如果剩余参数前面还有其他参数呢，比如：

```ts
function getSum2(x: number, ...nums: number[]): number {
  console.log(nums)//表示除了第一个参数，传入的参数组成的数组
  return nums.reduce(function (pre, curr) {
    return pre + curr;
  }, x);
}
// 这里x就表示1
console.log(getSum2(1, 2, 3, 4, 5)); //15
// 同上
console.log(getSum2(1, 2, 3, 4, 5, 6)); //21
```

剩余参数只能放在最后

```ts
function getSum(...nums: number[], y: number) {} // 报错
function getSum(y: number,...nums: number[]) {} // ok
```

### 函数重载

其实就是某个同名函数被声明了多次，但这里也分两种情况：

1.  参数个数一样，只是参数的数据类型不一样
2.  参数个数不一样

下面针对上述两种情况进行距离说明，第一种情况：

```ts
function getInfor(name: string): string;
function getInfor(age: number): number;
function getInfor(info: any): any {
  if (typeof info === "string") {
    return `我的名字是${info}`;
  } else {
    return `我的年龄是${info}`;
  }
}

console.log(getInfor("张三"));// 我的名字是张三
console.log(getInfor(13));//我的年龄是13
console.log(getInfor(true)); // 报错，因为你传的参数不符合任何一次声明中的参数类型
```

第二种情况

```ts
function getInfor(name: string): string;
function getInfor(name: string, age: number): string;
// 为啥最后一次带函数体的声明的时候age是可选参数呢，是因为前两次声明我们可以看到age是可传可不穿的呀
function getInfor(info: any, age?: number): any {
  if (age) {
    return `大家好，我叫${info},我今年${age}岁了`;
  } else {
    return `大家好，我叫${info}`;
  }
}

console.log(getInfor("张三", 28));//大家好，我叫张三,我今年28岁了
console.log(getInfor("张三"));//大家好，我叫张三
// console.log(getInfor(19)); // 报错，因为getInfo第一个参数必须是string类型
```

## TS函数中的this

### 1\. 只要全局调用，就是window

```ts
// 普通函数
function sayNames(name1: string, ...namesArr: string[]): void {
    console.log(this);// window
}
// 类函数
class Animal {
    name: string;
    constructor(name: string) {
        this.name = name;
    }
    bark() {
        return function (target: string) {
            console.log('小偷哪里跑！' + target);
            console.log(this);
        };
    }
}

let dog = new Animal('大黄');
let barkFun = dog.bark();
barkFun('汪汪汪');// window
```

### 2\. 在对象中，指向实例本身

```ts
// ts里面的this
class Animal {
    name: string;
    constructor(name: string) {
        this.name = name;
    }
    hobby(food: string = '大骨头') {
        console.log(`我喜欢吃${food}~~`); // Animal
        console.log(this);
    }
}

let dog = new Animal('大黄');
dog.hobby();
let barkFun = dog.bark();
barkFun('汪汪汪');
```

### 3\. call，apply和javaScript中一样

```ts
interface People {
    name: string;
}
const obj1 = {
    name: 'yj',
    getName(this: People) {
        return this.name;
    }
};
const obj2 = {
    name: 'zrj'
};
const obj3 = {
    name: 'haha'
};
console.log(obj1.getName.call(obj2));// zrj
console.log(obj1.getName.call(obj3));// haha
console.log(obj1.getName.call(obj4));//undefined
```

上述为什么要定义一个接口People，这是对通过call传入的`this`的类型进行约束，只能满足这个条件；虽然还是能够执行，但类型检查错误。
