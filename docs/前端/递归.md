# 递归

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/rlm9yb)

## 背景与思路

递归，说白了就是自己调用自己，但一定要有边界条件，不然会一直调用下去，造成内存泄漏

阶乘

## 代码示例

```js
// 典型的递归--阶乘
function facto(n) {
  if (n == 1) {// 边界条件
    return 1;
  } else {
    return n * facto(n - 1);
  }
}
console.log(facto(18));

```

斐契那波数列

```js
// 斐波那契数列
function fibonacci(n) {
  if (n == 0) { // 边界条件
    return 0;
  } else if (n <mark> 1 || n </mark> 2) { // 边界条件
    return 1;
  } else {
    return fibonacci(n - 1) + fibonacci(n - 2);
  }
}
console.log(fibonacci(1));//1
console.log(fibonacci(0));// 0
console.log(fibonacci(9));//34
```
