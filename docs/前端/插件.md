插件 (Plugins) 是一种能为 Vue 添加全局功能的工具代码，插件没有严格定义的使用范围，但是插件发挥作用的常见场景主要包括以下几种：

1.  通过 [app.component()](https://cn.vuejs.org/api/application.html#app-component) 和 [app.directive()](https://cn.vuejs.org/api/application.html#app-directive) 注册一到多个全局组件或自定义指令。
2.  通过 [app.provide()](https://cn.vuejs.org/api/application.html#app-provide) 使一个资源[可被注入](https://cn.vuejs.org/guide/components/provide-inject.html)进整个应用。
3.  向 [app.config.globalProperties](https://cn.vuejs.org/api/application.html#app-config-globalproperties) 中添加一些全局实例属性或方法
4.  一个可能上述三种都包含了的功能库 (例如 [vue-router](https://github.com/vuejs/vue-router-next))。

## 一、举个例子

### 1\. 注册插件

## 代码示例

```ts
import { App,h } from "vue";
// 选项数据
interface Options {
  name: string
}
export default {
  install(app: App, options:Options) {
    // options：可以在绑定的时候指定一些额外数据，但在使用该插件的时候，需要加上比如：app.use(testPlugin,{name:’张三‘})
    console.log(app, options);

    // 使用app.provide注入全局的数据，正常使用pages就行了
    app.provide('pages',19);

    // 全局自定义指令，如果v-showName = “’张三’”，显示，否则不显示
    app.directive('showName',(el,binding)=>{
      console.log(el,binding,options);
      if(binding.value==='张三'){
        el.style.display="block";
      }else{
        el.style.display="none";
      }
    })

    // 定义全局方法或属性，相当于Vue2.x中的Vue.prototype.xx = 
    app.config.globalProperties.$log = function(msg:string){
      return  msg+'方法呀'
    }

    // 全局自定义组件
    app.component('compoName',某个组件)

    // 函数式组件
    app.component('hola',{
      render(){
        return h("h2", null,'哈哈这是一个测试')
      }
    })
  },
};

```

### 2\. 安装插件

在入口文件`main.ts`中引入插件：

```ts
import testPlugin from "./plugins/index"; // 引入插件
const app = createApp(App);
app.use(testPlugin,{
  name:'李白'
})

```

### 3\. 在组件中使用：

```vue
<template>
<!-- 使用组件hola -->
  <hola></hola>
  
  <div>
    <!-- 自定义指令 -->
    <h1 v-showName="'张三'" >大打发发发</h1>
    
    <!-- 直接使用插件中的方法$log -->
    <h1 >{{ $log('测试app.config.globalProperties方法') }}</h1>
    
    <!-- 使用provide数据 -->
    <h1>{{injectData}}</h1>
  </div>
</template>

<script lang="ts">
import { defineComponent, onMounted, reactive, ref, toRefs,getCurrentInstance，inject } from "vue";
export default defineComponent({
  name: "list",
  setup() {
    const injectData = inject('pages')
    const instance = getCurrentInstance(); // 获取当前组件实例
    // 在setup中使用全局注册的属性或方法
    console.log(instance?.proxy?.$log('哈喽呀'));
  },
});
</script>
```

## 二、给拓展全局属性添加类型支持

某些插件会通过 [app.config.globalProperties](https://cn.vuejs.org/api/application.html#app-config-globalproperties) 为所有组件都安装全局可用的属性。举例来说，我们可能为了请求数据而安装了 `this.$http`，或者为了国际化而安装了 `this.$translate`。为了使 TypeScript 更好地支持这个行为，Vue 暴露了一个被设计为可以通过 [TypeScript 模块扩展](https://www.typescriptlang.org/docs/handbook/declaration-merging.html#module-augmentation)来扩展的 `ComponentCustomProperties` 接口：

```js
//  封装Axios请求
import axios from "axios";
import {AxiosInstance} from "axios";
import { ElMessage } from "element-plus";
enum CodeInt {
  "请求成功" = 200,
  "请求异常" = 501,
}
// 类型声明
declare module 'vue' {
  interface ComponentCustomProperties {
    $http: AxiosInstance;
  }
}
// 创建实例
const $http = axios.create({
  baseURL: "/api", // 所有的请求都会在请求路径前添加"/api"
  timeout: 5000, // 超时
  // 请求头
  headers: {
    "Content-Type": "application/json;chartset=utf-8",
  },
});

// 请求发送之前进行拦截,
$http.interceptors.request.use((config) => {
  config.headers = config.headers || {}; // 请求头
  // config.headers.token = 123,一般应该是从缓存中拿的
  return config;
});

//对返回结果进行拦截
$http.interceptors.response.use(
  (res) => {
    const code: number = res.data?.code;
    if (code !== 200) {
      ElMessage.error(CodeInt[code]);
      return Promise.reject(res.data);
    } else {
      return res.data;
    }
  },
  (err) => {}
);
export default $http;

////////////////////////////////////分割线//////////////////////////////////////
declare module 'vue' {
  interface ComponentCustomProperties {
    $http: typeof axios
    $translate: (key: string) => string
  }
}
或者

declare module '@vue/runtime-core' {
  interface ComponentCustomProperties {
    $http: AxiosInstance;
  }
}

```

在入口文件中注入

```ts
import $http from '@/common/http'
app.config.globalProperties.$http = $http

```

但是在组件中要使用`$http`，必须使用`getCurrentInstance()`，但其值可能是`null`，在TS中就可能会报错，那么如何解决呢？可以使用断言，例如：

```html
<script lang="ts" >
import { getCurrentInstance, ComponentInternalInstance } from "vue";
export default {
  setup () {
    // 断言
    const { proxy } = getCurrentInstance() as ComponentInternalInstance;
    // proxy?.$http
    return {
      
    }
  }
}
</script>
```
