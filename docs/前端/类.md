其实TS中的类和ES6中的类差不多，都是需要用关键字`class`，下面就类的相关知识进行解析。

## 类的定义

使用`class`进行定义，不过其本质还是一个函数，`class`只不过是一个语法糖而已。

## 代码示例

```ts
// ES6中的类
class Animal {
  constructor() {
    //这里面定义的属性都是实例属性
    this.name = "张三";
  }
  eat() {
    console.log("我喜欢吃肉！");
  }
}
// 等同于
class Animal {
  name = '张三';// 感觉很奇怪，不过习惯就好了,相当于默认值
  eat() {
    console.log("我喜欢吃肉！");
  }
}

```

还有这样的

```ts
// TS中的类
class Greeter {
    greeting: string;// 实例属性，没默认值，指明类型
    constructor(message: string) {
        this.greeting = message;
    }
    greet() {
        return "Hello, " + this.greeting;
    }
}

let greeter = new Greeter("world");
```

## 类的继承

使用关键字`extends`，例如`class A exends B`，表示将来类`A`的实例会继承`B`的属性和方法，继承使用`super`方法，相当于把`B`中的`contsrcutor`内部调用了`A`的`constructor`：

```ts
class Person extends Animal {
  constructor(){
  	super();// 相当于复制了一份Animal中的constructor内部代码
  },
  func() {
    console.log("我能制造工具！");
  }
}
let person = new Person();
person.eat();
person.func();
```

上述，Person会继承Animal中的属性和方法，也就意味着Person对应的实例能够像Animal实例一样访问其属性和方法。

但是如果你想在字类中设置新的属性或方法，就要首先在子类的构造函数中调用`super`方法，例如：

```ts
class Person1 {
  constructor(public name: string) {
    this.name = name;
  }
  sayHello() {
    console.log(`hello，大家好，我是${this.name}`);
  }
}

// 继承
class Teacher extends Person1 {
  constructor(public age: number) {
    super("张三"); //要想继承上述的实例属性和方法必须调用super
    this.age = age;// 字类的新实例属性
  }
  sayAge() {
    console.log(`我今年${this.age}岁了！`);
  }
}

let chineseTeacher = new Teacher(19);
console.log(chineseTeacher);//{ name: '张三', age: 19 }
```

但如果想要在子类中调用父类的方法怎么办呢？直接在子类的对应函数中使用`super.fn([param])`即可，如下面的例子：

```ts
class Person1 {
    name: string;
    age: number;
    constructor(name: string, age: number) {
        this.name = name;
        this.age = age;
    }
    sayHello(str: string): void {
        console.log(`${str}，我是${this.name}，今年${this.age}岁了`);
    }
}

class Teacher extends Person1 {
    sex: string;
    constructor(name: string, age: number, sex: string) {
        // 调用父类的构造函数
        super(name, age);
        this.sex = sex;
    }
    sayHi() {
        console.log(this.sex);
        // 调用父类的方法
        super.sayHello('HELLO');
    }
}
```

当然在子类中也可以重写父类的方法，这里不再赘述。

## 类的多态

其实就是父类型的引用指向了子类型的对象（其实就是用父类型去约束子类型的实例），不通子类型的对象在访问相同的方法，产生了不同的行为（其实际上访问的就是子类的方法）。

```ts
// 定义一个父类
class Animal {
    name: string;
    constructor(name: string) {
        this.name = name;
    }
    run(distance: number = 10): void {
        console.log(`一口气跑了${distance}米，${this.name}`);
    }
}
// 子类Dog
class Dog extends Animal {
    constructor(name: string) {
        super(name);
    }
    run(distance: number = 20): void {
        console.log(`一口气跑了${distance}米，${this.name}`);
    }
}

// 子类Cat
class Cat extends Animal {
    constructor(name: string) {
        super(name);
    }
    run(distance: number = 30): void {
        console.log(`一口气跑了${distance}米，${this.name}`);
    }
}

let ani: Animal = new Animal('佩奇');
ani.run(); // 一口气跑了10米，佩奇
let dog: Dog = new Dog('旺财');
dog.run(); // 一口气跑了20米，旺财
let cat: Cat = new Cat('加菲猫');
cat.run(); // 一口气跑了30米，加菲猫

// 但是，如果这样呢？以父类Animal的类型创建子类Dog,Cat的对象
let dog1: Animal = new Dog('大黄');
dog1.run(); // 一口气跑了20米，大黄
let cat1: Animal = new Cat('Kitty');
cat1.run(); // 一口气跑了30米，Kitty

```

为什么，明明上面的`dog1`，`cat1`受到了`Animal`的约束呀，但为啥还是依旧执行的是子类的`run`方法呢，我的理解是上面的`Animal`仅仅只是起到了约束的作用。但最关键的是你创建实例的时候是子类的实例，那么当然执行的是子类的方法啦！

## 公共和私有属性

这里会涉及到三个关键字`public`，`private`，`protected`，用来描述该属性（方法）的访问性质，**默认是**`**public**`**。**

### public

公共属性在类的内部和外部都能访问，这里所谓**内外是相对于大括号**`**{}**`**的：**

```ts
class Animal {
    public name: string; // constructor定义的实例属性要在此进行类型定义
    constructor(theName: string) {
        this.name = theName;
    }
    public move(distanceInMeters: number) {
        console.log(`${this.name}移动了${distanceInMeters}m~`);
    }
}

let dog = new Animal('大黄');
console.log(dog);// 大黄
dog.move(100); // 大黄移动了100m~
```

### private

使用该关键字进行标记，该属性（方法）不能在类的外部访问，还是上面的例子：

```ts
class Animal1 {
    private name: string; // constructor定义的实例属性要在此进行类型定义
    constructor(theName: string) {
        this.name = theName;
    }
    private move(distanceInMeters: number) {
        console.log(`${this.name}移动了${distanceInMeters}m~`);
    }
}

let dog1 = new Animal1('大黄');
console.log(dog1.name);// 报错
dog1.move(100);
```

### protected

只能在类的内部访问和继承类的内部进行访问：

```ts
class Person {
    protected name: string;
    constructor(name: string) {
        this.name = name;
        console.log(this.name); // 在类内部能够进行访问
    }
}

class Employee extends Person {
    private department: string;
    constructor(name: string, department: string) {
        super(name);
        this.department = department;
    }
    public getElevatorPitch() {
        return `Hello, my name is ${this.name} and I work in ${this.department}.`;
        //Employee类是Person派生出来的，现在Employee类内部可以访问name属性
    }
}

let howard = new Employee('Howard', 'Sales');
console.log(howard.getElevatorPitch());// 正常打印，因为实际上在访问的时候还是在内部访问的
console.log(howard.name); // 报错，这里已经是在Employee类的外部了
```

## Getter,Setter和static和readonly

### Getter和Setter

Getter其实就是计算属性，可以用来获取类的某些私有属性或方法，Setter可以重置某些属性或方法：

```ts
class Person2 {
  constructor(private name: string) {
    this.name = name;
  }
  //getter,就像计算属性一样，可以用来获取某些私有属性或者格式化某个属性
  get myName() {
    return `哈喽,${this.name}先生`;
  }
  set setMyName(name: string) {
    console.log("设置name属性中...");
    this.name = name;
  }
  sayMyName() {
    console.log(this.name);
  }
}
let person = new Person2("张三");
console.log(person.myName); //因为读取了myName属性，所以是“哈喽,张三先生”
person.setMyName = "李四"; // 触发setMyName函数，重新设置name属性
console.log(person.myName); // 哈喽,李四先生
```

### static

可以在属性或方法的前面添加`static`关键字，表示当前的属性和方法是设置在了类自己身上的，而不是类的实例上，**也就是说只有类本身可以访问这些属性或方法**，例如：

```ts
class Girl {
  constructor(){
  }
  // 静态方法
  static sayLove() {
    return `I Love You`;
  }
  // 静态属性
  static age:number = 19; // 默认是19
}

// let girl = new Girl();
 console.log(girl.sayLove());//报错
console.log(Girl.sayLove()); // I Love You
console.log(Girl.age); // 19
```

### readonly

表示只读属性，只读属性必须在声明时或构造函数里被初始化，不能在外部修改`readonly`的属性，例如：

```ts
class Octopus {
    readonly name: string;
    readonly numberOfLegs: number = 8;// 声明时进行初始化
    constructor (theName: string) {
        this.name = theName;// 构造函数进行name属性的初始化
    }
}
let dad = new Octopus("Man with the 8 strong legs");
dad.name = "Man with the 3-piece suit"; // 错误! name 是只读的.
```

其次，在类内部的普通函数内部也不能修改`readonly`属性，例如：

```ts
class Girl {
    readonly name: string;
    constructor(name: string) {
        this.name = name;
    }
    sayName() {
        console.log(this.name);
        this.name = '超大甜甜';// 报错
    }
}
```

constructor中的参数是只读的呢，其实也是一样的，都不能被修改：

```ts
class Girl {
  //构造函数，参数name是只读属性，
    constructor(readonly name: string) {
        this.name = name;
    }
    sayName() {
        console.log(this.name);
      	this.name = '超大甜甜'
    }
}

let girl: Girl = new Girl('小甜甜');
console.log(girl);
girl.sayName(); // 报错
girl.name = '大甜甜'; // 报错
girl.sayName();

```

> 构造函数的参数一旦使用readonly进行修饰，那么Girl中就已经存在属性name，不需要再进行声明，同理，public和private

总之一句话，被`readonly`修饰的属性最好不要修改。

## 抽象类

抽象类，表示对某些特定类的属性或方法的抽象，用继承（`extends`）进行抽象和特定类进行关联,**也可以这么说抽象类只负责抽象,具体的类(子类)负责实现，这也另一方面说明了抽象类不能被实例化**，例如：

```ts
// 抽象类
abstract class Animal1 {
    // 抽象属性name
    abstract age: number;
    // 抽象类的抽象方法，
    abstract eat(): void;
    // 实例方法
    sleep() {
        console.log('哈哈，我要睡觉了');
    }
}

// 抽象类的实例方法会被自动机继承到子类中，所以不需要再在子类中进行声明和定义
class Pig extends Animal1 {
    age: number;
    name: string;
    constructor(name: string) {
        // 在子类中，要想使用构造函数必须调用一次super
        super();
        this.name = name;
    }
    // 在实例中对eat方法进行具体的实现
    eat() {
        console.log('我爱吃玉米');
    }
}
let pig: Pig = new Pig('佩奇');
console.log(pig);
pig.sleep();

// 在次实例化
class LittleFish extends Animal1 {
    age: number = 12; //具体实现，并且还有默认值
    name: string;
    constructor(name: string) {
        // 在子类中，要想使用构造函数必须调用一次super
        super();
        this.name = name;
    }
    // 在实例中对eat方法进行具体的实现
    eat() {
        console.log('我爱吃虾米');
    }
}
let littleFish: LittleFish = new LittleFish('黄河小鲤鱼');
console.log(littleFish);
littleFish.sleep();

```

> 虽然抽象类中的属性和方法均可以被抽象，但更多的是抽象方法，抽象属性不常用
