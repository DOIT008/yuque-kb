# 生命周期

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/eqlewz)

Vue3的声明周期其实和Vue2.x的生命周期差不多，只不过写法有所区别，毕竟Vue3使用的是CompositionAPI。

另外，因为`setup`是围绕`beforeCreate`和`created`这两个钩子运行的(**也就意味着**`**setup**`**最先执行**)，所以就不需要显式地进行定义他们了，但是其他钩子需要在`setup`函数中进行定义:

Vue2.x 选项式API | CompositionAPI （setup）
--- | ---
beforeCreate | 无
created | 无
beforeMount | onBeforeMount
mounted | onMounted
beforeUpdate | onBeforeUpdate
updated | onUpdated
beforeUnmount | onBeforeUnmount
unmounted | onUnmounted
errorCaptured | oneErrorCaptured
renderTracked | onRrenderTracked
renderTriggered | onRenderTriggered

> 你会发现在`setup`函数中的这些钩子基本上都是在Vue2.x对应的钩子前面加`on`

## 验证一下

## 代码示例

```vue
<script>
import { onMounted } from "vue";
export default {
  setup() {
    console.log("setup");
    // 生命周期
    onMounted(() => {
      console.log("onMounted"); // 生命的起源
    });
    onBeforeMount(() => {
      console.log("onBeforeMount");
    });
  },
  beforeCreate() {
    console.log("beforeCreate");
  },
  created() {
    console.log("created");
  },
};
</script>

// 输出结果
setup
beforeCreate
created
onBeforeMount
onMounted
```

## 总结

既然`setup`是围绕着`beforeCreate`和`created`运行的，那么也就意味着原来在上述两个钩子可以做的事情交给`setup`来做就行了。也就是说`setup`是在`beforeCreate`之前执行的
