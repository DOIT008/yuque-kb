## 说明

大型应用中，我们可能需要将应用分割成小一些的代码块，并且只在需要的时候才从服务器加载一个模块。为了简化，Vue 有一个 `defineAsyncComponent` 方法：

定义一个异步组件的方法，满足以下三个条件：

1.  **必须明确**使用`defineAsyncComponent` 方法
2.  如果是可配置的异步组件上述的方法要传入一个包含loader属性的对象

## 代码示例

```vue
//asyncCompo.vue
<template>
  <div>我是一个异步组件</div>
</template>

<script>
export default {
  setup() {
    return {};
  },
};
</script>

<style lang="scss" scoped></style>
```

使用异步组件--setup script写法

```vue
<template>
  <div>
    <!-- 异步组件 -->
    <AsyncComponent></AsyncComponent>
  </div>
</template>

<script setup>
    import {
      reactive,
      ref,
      defineProps,
      defineEmit,
      useContext,
      defineAsyncComponent,
    } from "vue";
    import TestFunc from "./FuncCompos.vue";

    // 异步组件
    const AsyncComponent = defineAsyncComponent(() => import("./asyncComp.vue"));
  </script>
```

传统写法

```vue
<template>
  <div>
    <!-- 异步组件 -->

</template>

<script>
    import {

    	AsyncComponent:defineAsyncComponent(() => import("./asyncComp.vue"))
    }
  </script>
```

## 可配置的异步组件

还是以上面的为例：

```js
const AsyncComponent = defineAsyncComponent({
  loader: () => import("./asyncComp.vue"),
  timeout: 2000, // 2000ms还没渲染出来就要errorComponent了
  delay: 200, //延迟200ms再渲染
  errorComponent: ErrorComponent, //表示发生错误的时候要渲染的组件
  loadingComponent: LoadingComponent, //该异步组件加载中的组件
});
```
