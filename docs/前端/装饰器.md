## 定义

装饰器就是一种特殊的类型声明，他能够被附加到**类（class）**声明、方法、属性或参数上，可以修改类的行为。

其实通俗的讲，**装饰器就是一个方法（函数）**，可以被注入到 类、方法、属性参数上来**扩展**类、方法、参数和属性的功能。

## 分类

按使用场景分：类装饰器，属性装饰器，方法装饰器，参数装饰器

按装饰器类别分：一般装饰器（无法传参），装饰器工厂（可以传参）

## 举例

### 类装饰器

顾名思义就是应用在类上的装饰器，在类声明之前被声明，应用于类构造函数，可以用来监视，修改或者替换类定义，要传入一个参数

#### 一般装饰器

不传入任何参数，可以修改类原型上的属性或方法

## 代码示例

```ts
// 声明一个装饰器
function decur(param: any) {
  console.log(param); // 打印出来的是Person6本身
  // 所以我们可以进行修改Person6的属性或方法
  param.prototype.eat = function () {
    console.log(this.name + "喜欢吃冰淇淋");
  };
  param.prototype.age = 17;
}

// 使用装饰器
@decur
class Person6 {
  name: string;
  constructor(name: string) {
    this.name = name;
  }
  say(): void {
    console.log(`早上好${this.name}`);
  }
}

let person6: any = new Person6("谢大脚");
person6.say();//早上好谢大脚
console.log(person6.age); //17
person6.eat(); //谢大脚喜欢吃冰淇淋
```

#### 装饰器工厂

需要在装饰器函数内部返回一个函数，该函数的参数就是类本身

```ts
function decur(param: string) {
  // param是装饰器本身参数，
  return function (target: any) {
    // target就是将来的Person6类，在这里面扩展Person6类
    console.log(param, target);
    target.prototype.eat = function () {
      console.log(this.name + "喜欢吃冰淇淋");
    };
    target.prototype.age = 17;
  };
}

@decur("张三") // 直接就执行了，传了参数张三
class Person6 {
  name: string;
  constructor(name: string) {
    this.name = name;
  }
  say(): void {
    console.log(`早上好${this.name}`);
  }
}

let person6: any = new Person6("谢大脚");
person6.say(); // 谢大脚喜欢吃冰淇淋
console.log(person6.age); //17
person6.eat(); //谢大脚喜欢吃冰淇淋
```

#### 类构造器修改构造函数constructor

类装饰器修改类的构造函数,就如同下面的方法，使用`class extends` 参数，如下所示：

```ts

function reWrite(param: any) {
  return class extends param {
    name: string = "李四";// 修改constructor中this.name
    sayName(): void {// 修改sayName方法
      console.log(this.name + "-----");
    }
  };
}

@reWrite
class Animal9 {
  name: string;
  constructor() {
    this.name = "张三";
  }
  sayName(): void {
    console.log(this.name);
  }
}

let ani = new Animal9();
console.log(ani.name); // 李四
ani.sayName(); // 李四----
```

### 属性装饰器

属性装饰器会在运行时会被当作函数调用，传入**两个参数**： 1.对于静态成员而言是类构造函数， 对实例成员而言是类的原型对象。2. 属性名称

```ts
// 
function logProperty(param: any) {
  return function (target: any, attr: string) {
    console.log(param, target, attr); //王五 {sayName: ƒ, constructor: ƒ} name
  };
}

class Animal5 {
  @logProperty("王五")
  name: string;
  constructor() {
    this.name = "张三";
  }
  sayName(): void {
    console.log(this.name);
  }
}
```

### 方法装饰器

用在方法的属性描述符上，可以用来修改监视，修改或者替换方法定义。方法装饰器会在运行时传入以下**几个参数**：

1\. 对静态成员来说是类的构造函数，对实例成员来说是类原型对象

2\. 成员的名字（其实就是方法名）

3\. 成员的属性描述符(描述这个函数的一个对象)

例如

```ts
//方法装饰器
function logMethod(params: any) {
  return function (target: any, member: any, desc: any) {
    console.log(target); //{eat: ƒ, constructor: ƒ}
    console.log(member); //eat
    console.log(desc); //
    // {
    //   value: [Function],
    //   writable: true,
    //   enumerable: true,
    //   configurable: true
    // }
  };
}

class Animal0 {
  name: string;
  constructor(name: string) {
    this.name = name;
  }
  @logMethod("哈喽")
  eat() {
    console.log("我喜欢吃大骨头");
  }
}

```

添加属性和方法

```ts
function logMethod(params: any) {
  return function (target: any, member: any, desc: any) {
    console.log(target); //{eat: ƒ, constructor: ƒ}
    console.log(member); //eat
    console.log(desc);
    // 添加属性和方法
    target.logUrl = "http://XXXX";
    target.say = function () {
      console.log("哈喽，早上好！");
    };
  };
}

class Animal0 {
  name: string;
  constructor(name: string) {
    this.name = name;
  }
  @logMethod("哈喽")
  eat() {
    console.log("我喜欢吃大骨头");
  }
}

let animal = new Animal0("大黄");
animal.say(); // 哈喽，早上好！
console.log(animal.logUrl); //http://XXXX

```

修改方法

```ts
function logMethod(params: any) {
  return function (target: any, member: any, desc: any) {
    console.log(target); //{eat: ƒ, constructor: ƒ}
    console.log(member); //eat
    console.log(desc);
    desc.value = function () {
      console.log("我喜欢吃肉肉"); // 我喜欢吃肉肉
    };
  };
}

class Animal0 {
  name: string;
  constructor(name: string) {
    this.name = name;
  }
  @logMethod("哈喽")
  eat() {
    console.log("我喜欢吃大骨头");
  }
}

let animal = new Animal0("大黄");
animal.eat(); //我喜欢吃肉肉
```

### 方法参数装饰器(不常用)

参数装饰器表达式会在运行时当作函数被调用，可以使用参数装饰器为类的原型增加一些数据，传入下列三个参数： 1. 对于静态成员来说是类的构造函数，对于实例成员是类的原型对象

2\. 方法的名称。

3\. 参数在函数参数列表中的索引。

```ts
// 装饰器
function logParams(param: any) {
  return function (target: any, methodName: string, index: number) {
    console.log(param); //嘿嘿嘿
    console.log(target); //Animal10 { eat: [Function] }
    console.log(methodName); // eat
    console.log(index); //0
    target.url = "www.baidu.com";
  };
}

// 类
class Animal10 {
  name: string;
  constructor(name: string) {
    this.name = name;
  }
  
  // 装饰的是age参数，如果有多个参数，可以像这样 (@logParams("嘿嘿嘿") age: number，@logParams("嘿嘿嘿") kk: string)
  eat(@logParams("嘿嘿嘿") age: number) {
    console.log(age);
  }
}

let animal10 = new Animal10("旺财");
animal10.eat(10);
console.log(animal10.url); //www.baidu.com
```

## 装饰器执行顺序

总体：属性装饰器-->方法装饰器-->方法参数-->类装饰器。

如果有多个同类装饰器，会先执行后面的，再执行前面的
