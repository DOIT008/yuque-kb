## 代码示例

```vue
<template>
  <div>

```

 

```vue
// 子组件 helloWorld.vue
<script>
	export default {
    name: "HelloWorld",
    props: {
      msg: String,
      //注意对于 kebab-case的属性名，在props中要转化成camelCase格式的
      customEvent:String,
    },

      counter2,
    },
    data() {
      return {

      };
    },
  };

```

其实props内的数据可以有多种形式：

```ts
Vue.component('my-component', {
  props: {
    // 基础的类型检查 (`null` 和 `undefined` 会通过任何类型验证)
    propA: Number,
    // 多个可能的类型
    propB: [String, Number],
    // 必填的字符串
    propC: {
      type: String,
      required: true
    },
    // 带有默认值的数字
    propD: {
      type: Number,
      default: 100
    },
    // 带有默认值的对象
    propE: {
      type: Object,
      // 对象或数组默认值必须从一个工厂函数获取
      default: function () {
        return { message: 'hello' }
      }
    },
    // 自定义验证函数
    propF: {
      validator: function (value) {
        // 这个值必须匹配下列字符串中的一个
        return ['success', 'warning', 'danger'].indexOf(value) !== -1
      }
    }
  }
})
```

基本上和Vue2.x的一样，更多的请参考[官网Props](https://cn.vuejs.org/v2/guide/components-props.html)。

### refs

refs获取子组件内部某个函数，直接调用传参（这里简称refs方式），具体而言就是给子组件添加`ref`属性，然后再父组件内部通过`ref`获取子组件实例，再调用子组件内部改变数据的方法。

子组件

```vue
// counter2.vue
<template>
  <div>{{ title }}</div>
</template>

<script>
import { ref, defineComponent } from "vue";
export default defineComponent({
  name: "counter2",
  setup() {
    // 初始化为空
    let title = ref("");
    // 设置title的值
    function setTitle(val) {
      title.value = val;
    }
    
    return {
      title,
      setTitle,
    };
  },
});
</script>

<style lang="scss" scoped></style>

```

父组件

```vue
// helloWorld.vue
<template>
  <div class="container">
    <h1>{{ msg }}</h1>
    <!-- 这里ref接受的字符串，要setup返回的ref类型的变量同名，也就是说这里是counter2,将来变量ref()变量名必须是counter2 -->
    <counter2 ref="counter2"></counter2>
    <button @click="sendSonData">父to子</button>
  </div>
</template>

<script>
import counter2 from "/@/pages/counter2.vue";
import { ref, reactive, toRefs, defineComponent } from "vue";
export default defineComponent({
  name: "HelloWorld",
  components: {
    counter2,
  },
  setup() {
    // 这里变量名就必须是counter2
    const counter2 = ref(null);

    function sendSonData() {
      // counter2.value是子组件counter2本身，调用子组件setTiitle方法
      counter2.value.setTitle("张三");
    }
    return {
      sendSonData,
      counter2,
    };
  },
});
</script>
<style lang="scss"></style>

```

## 子to父

### emit

在自定义组件中使用`setup`的第二个参`context.emit`来抛出一个自定义事件，然后在父组件上使用`@`监听该事件即可，

或者在模板种使用`$emit`也是一样的，例如：

```vue
// helloWorld.vue
<template>
  <div class="container">
    <button @click="sendSonData">子to父</button>
    <button @click="$emit('hello',userInfo)">子to父</button>
  </div>
</template>

<script>
import { ref, reactive, toRefs } from "vue";
export default {
  name: "HelloWorld",
  props: {
    msg: String,
  },
  emits:['hello'],//在抛出的自定义事件之前最好还是在这个选项中注册一下，其值也可以是一个对象（可以进行更详细的配置）
  setup(props, context) {
    // props 父to子的传递过来的数据，
    // context 上下文对象
    const userInfo = reactive({
      name: "张三",
      age: 6,
    });

    function sendSonData() {
      // 使用context.emit抛出事件
      context.emit("hello", userInfo);
    }
    return {
      ...toRefs(userInfo),
      sendSonData,
    };
  },
};
</script>

```

在父组件中

```vue
<template>
  <div>
    <img alt="Vue logo" src="./assets/logo.png" />
    <!-- @hello监听 -->
    <HelloWorld @hello="handleGetData" msg="Hello Vue 3.0 + Vite" />
  </div>
</template>

<script>
import HelloWorld from "/@/components/HelloWorld.vue";
export default {
  name: "App",
  setup() {
    // 定义事件
    function handleGetData(data) {
      console.log(data);
    }
    return {
      // 抛出来才能在 外部使用呀
      handleGetData,
    };
  },
  components: {
    HelloWorld,
  },
};
</script>

```

更多参考官网关于[emits的介绍](https://v3.cn.vuejs.org/api/options-data.html#emits)。

## 父to孙

### provide和inject

在父组件使用provide函数，如下：

父组件

```vue
// App.vue
<script>
import HelloWorld from "/@/components/HelloWorld.vue";
// 需要引入provide
import { ref, provide } from "vue";
export default {
  name: "App",
  setup() {
    let title = ref("我是来自父组件的标题");
    // provide是一个函数，将title提供给孙子组件
    provide("title", title);
  },
  components: {
    HelloWorld,
  },
};
</script>
```

孙子组件

```vue
// counter2.vue
<template>
  <div>{{ title }}</div>
<!--我是来自父组件的标题-->
</template>

<script>
// 引入inject方法
import { inject, ref } from "vue";
export default {
  setup() {
    // 这里inect函数参数对应，provide函数的第一个参数
    let title = inject("title");
    // 带默认值的title,hello,title是默认值
    let title = inject("title",'hello,title');
    return {
      title,
    };
  },
};
</script>

```

但是和Vue2.X不一样的是，**Vue3中的**`**provide**`**和**`**inject**`**是双向数据流**，也就意味着，如果你在孙子组件改变数据，也会影响到父组件对应的数据。但是**建议尽可能，在*****提供者*****内保持响应式 property 的任何更改**。也就是说最好在父组件内更改数据。

所以，为了防止在孙子组件内修改数据，可以使用`readonly`方法对`provide`的数据进行包裹，这样数据就不是响应式的了，例如：

```js
 import { ref, provide,readonly } from "vue";
setup() {
    let title = ref("我是来自父组件的标题");
    // readonly,孙子组件内的inject数据不能在组件内修改
    provide("title", readonly(title));
  },
```
