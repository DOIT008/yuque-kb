# 对比

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/he4cl9)

## 个人总结

1.  Vue3虽然有了CompositionAPI，但并不是一定要用，你依然可以使用OptionAPI
2.  Vue3的组件模板`<template>`没有根元素也可以
3.  其实Vue3保留了Vue2.x的很多API，包括用法都没变😂
4.  Vue3不再支持过滤器（filter），其建议使用计算属性
5.  Vue3 对数据的处理比较统一——**无论数组是啥类型的（数组，基本类型，还是对象？）都可以直接进行赋值，而且赋值完之后依然是响应式的数据**，包括数组的各种方法，而不是像Vue2.x那样，如果改变对象的属性还要用`this.$set（哪个对象，property，val）`，对于数组`this.$set（数组，index，val）`

## $on，$off，$once被移除

可以通过第三方库实现，比如[mitt](https://blog.csdn.net/fuweipeng2012/article/details/113812794)库，也就是没有了事件中心

## 没有了filters选项
