## 一、一般路由配置

初始化项目的时候会在项目的根目录`pages`有一个初始页面`index.vue`：

## 代码示例

```latex
pages
-index.vue

```

![image.png](/images/a6f4243578187a07.png)

以后所有的页面都要写在该目录下，当然也可以创建子文件夹方便管理，如上面的`detail/index.vue`

### 1\. 路由导航

使用`nuxt-link`组件(和vue3中的`router-link`组件差不多，其实最后也是转化成`router-link`)，通过`to`属性导航，同时该标签支持`activeClass`属性和`tag`属性：

```vue
<template>
  <!-- 初始页，没有所谓的根组件 -->
  <div class="container">
    <h1>这是初始化页</h1>
    <!-- 路由，将来会转化为router-link，这里导航到/list，将来组件的名字也要是list.vue -->
    <nuxt-link to="/list">列表</nuxt-link>
    <!-- 当然也可以创建子文件夹如下面的detail（要和to的参数值保持一致），文件名一般是index.vue,其他文件名不行 -->
    <nuxt-link to="/detail">详情</nuxt-link>
  </div>
</template>
<script lang="ts">
import Vue from 'vue'

export default Vue.extend({
  name: 'IndexPage',
})
</script>

```

## 二、嵌套路由

创建内嵌子路由，你需要**添加一个 Vue 文件**，同时添加一个与**该文件同名的目录**用来存放子视图组件。

如下面的页面结构：

```latex
--|pages/
----|parent/
------|child1.vue
------|child2.vue
------|index.vue
----|parent.vue
```

解释一下：

1.  `parent.vue`是在访问`/parent`时展示的内容，里面通常会有`nuxt-link`和`nuxt-child`（显示嵌套路由内容的地方）组件。
2.  `child1.vue`和`child2.vue`就是在访问嵌套路由`/parent/child1`或`parent/child2`在`nuxt-child`位置展示的内容。
3.  `index.vue`时在访问`/parent`时在`nuxt-child`位置默认展示的内容。

​  

下面看下各个组件的内容吧：

```vue
<template>
  <div>
    <h3>这里是parent页面</h3>
    <!-- 导航区 -->
    <nuxt-link to="/parent/child1">child1</nuxt-link>
    <nuxt-link to="/parent/child2">child2</nuxt-link>
    <!-- 内容区 -->
    <div class="content">
      <nuxt-child />
    </div>
  </div>
</template>

<script>
export default {}
</script>

<style lang="scss" scoped></style>

```

```js
  }],

}
```

## 三、动态路由

如果我们在文件名或者文件夹名以**下划线“\_”作为前缀（只能是以“\_”开头）**，他们将被转化为**动态路由**参数，例如下面的结构：

```latex
-|pages
--|_group/
---|_id.vue
```

上述案例我们可以在`_id.vue`中访问到`id`和`group`属性。

```vue
<template>
  <div class="user-info">
    <h3>id:{{ $route.params.id }}</h3>
    <h3>group:{{ $route.params.group }}</h3>
  </div>
</template>

<script lang="ts">
import Vue from 'vue'
export default Vue.extend({
  name: 'userPage',
})
</script>

```

其实在`.nuxt/router.js`中编译成了：

```json
{
    path: "/:group/:id?",
    component: _29a66bb5,
    name: "group-id"
},
```

那么同理，更多的情况如下结构：

![image.png](/images/cd9fcabd10a18f74.png)

上述被编译成了如下：

```js
export const routerOptions = {
  mode: 'history',
  base: '/',
  linkActiveClass: 'nuxt-link-active',
  linkExactActiveClass: 'nuxt-link-exact-active',
  scrollBehavior,

  routes: [{
    path: "/detail",
    component: _667bce9c,
    name: "detail"
  }, {
    path: "/list",
    component: _209e0433,
    name: "list"
  }, {
    path: "/team/:teamId?",
    component: _7dbad275,
    name: "team-teamId"
  }, {
    path: "/",
    component: _0e97020d,
    name: "index"
  }, {
    path: "/:project/projectItem",
    component: _01392426,
    name: "project-projectItem"
  }, {
    path: "/:group/:id?",
    component: _29a66bb5,
    name: "group-id"
  }, {
    path: "/:lists/:listId?/:id?",
    component: _4449b9ed,
    name: "lists-listId-id"
  }],

  fallback: false
}
```

对应的路由链接`Nuxt-link`

```vue
<template>
  <!-- 初始页，没有所谓的根组件 -->
  <div class="container">
    <h1>这是初始化页</h1>
    <!-- 路由，将来会转化为router-link，这里导航到/list，将来组件的名字也要是list.vue -->
    <nuxt-link to="/list">列表</nuxt-link>
    <!-- 当然也可以创建子文件夹如下面的detail（要和to的参数值保持一致），文件名一般是index.vue,其他文件名不行 -->
    <nuxt-link to="/detail">详情</nuxt-link>
    <!-- 既有文件夹又有文件名带“_” -->
    <nuxt-link to="/zsf/123">zsf/123</nuxt-link>
    <!-- 文件名带“_” -->
    <nuxt-link to="/team/456">team/456</nuxt-link>
    <!-- 文件夹带“_” -->
    <nuxt-link to="/nuxt/projectItem">nuxt/projectItem</nuxt-link>
    <!-- 多层携带参数“_” -->
    <nuxt-link to="/goals/G0012/GO3527">/goals/G0012/GO3527</nuxt-link>
  </div>
</template>
```
