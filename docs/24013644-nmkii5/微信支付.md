## JSAPI支付

商户已有H5商城网站，用户通过消息或扫描二维码在**微信内打开网页**时，可以调用微信支付完成下单购买的流程

::: tip
https://pay.weixin.qq.com/docs/partner/products/partner-jsapi-payment/introduction.html
:::

## H5支付

H5支付是指商户在**微信客户端外的移动端网页**展示商品或服务，用户在前述页面确认使用微信支付时，商户发起本服务呼起微信客户端进行支付。

::: tip
https://pay.weixin.qq.com/docs/partner/products/partner-h5-payment/introduction.html
:::

::: tip
https://pay.weixin.qq.com/doc/v3/merchant/4012791835
:::

## 小程序支付

商户已有微信小程序，用户通过好友分享或扫描二维码在微信内打开小程序时，可以调用微信支付完成下单购买的流程。（**小程序仅支持小程序支付**）

::: tip
https://pay.weixin.qq.com/docs/partner/products/partner-mini-program-payment/introduction.html
:::

## PC端微信

如需要在PC端网页中使用微信支付，请接入Native支付，文档详见[《Native支付》](https://pay.weixin.qq.com/doc/v3/partner/4012076267)。

```vue
<template>
  <div class="pay-success">
    <img src="../../assets/imgs/icon-pay-success.png" alt="">
    <p>支付成功</p>
    <van-button type="primary" @click="viewReport" block class="view-btn" round>查看报告</van-button>
  </div>
</template>

<script setup lang="ts" >
import { onMounted,ref } from 'vue'
import { useRoute } from 'vue-router'
import { getJudicialByOrderNoApi } from '@/api'
const route = useRoute()
const homeLink = ref<string>('')

// 初始化小票
function init() {
  var initData = {
    action: 'onIframeReady',
    displayStyle: 'SHOW_CUSTOM_PAGE'
  }
  var initPostData = JSON.stringify(initData)
  parent.postMessage(initPostData, '*')
  console.log("初始化");
  getOrderInfo()
}

// 获取订单信息
async function getOrderInfo() {
  const base = process.env.VITE_ENV === 'test' ? 'kcfly1eapp' : process.env.VITE_ENV === 'development' ? '' : 'app';
  const res = await getJudicialByOrderNoApi(route.query.out_trade_no); 
  const { queryType, judicialId, selfId } = res.data;
  // 测试环境||正式环境
  homeLink.value = `https://sffxcx.zzdsj.com/${base}/inquiry-report-self?queryType=${queryType}&id=${judicialId}&selfQueryId=${selfId}`;
}
//注册点击事件(去报告页)
function viewReport() {
  var mchData = {
    action: 'jumpOut',
    jumpOutUrl: homeLink.value //跳转的页面
  }
  var postData = JSON.stringify(mchData)
  parent.postMessage(postData, '*')
}

onMounted(() => {
  init();
})
</script>
```
