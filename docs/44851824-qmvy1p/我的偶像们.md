# 我的偶像们

> 来源：语雀「生活」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/qmvy1p/tv79t4w28gkntegb)

## 背景与思路

每个技术人心中都有一个“大神”梦，你也不例外...

和大神相比——

**你缺少的只是他们的专注和遇到困难时的淡定、以及解决掉它们所需要的耐心、决心和意志！**

**一个bug一个bug地解决吧！**

**一个坑一个坑地踩吧！**

**你要知道，你的现在就是他们的曾经呀！**

**每解决一个困难，就会成长一分，也就离“大神”更近一步，**

**感恩它们，因为它们是你走向卓越的垫脚石！**
