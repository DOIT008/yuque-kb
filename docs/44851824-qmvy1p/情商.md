# 情商

> 来源：语雀「生活」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/qmvy1p/mq60ra)

## 背景与思路

**所谓情商高，就是感知别人情绪的能力，根据别人不同的情绪，说不同的话。**

说话前要三思而行，不要张口就来，不过脑子...，以免弄巧成拙

有位作家曾说：**“情商高是一种人性的修炼，高情商者能够灵敏的体会他人的情绪及立场，察觉他人的真正情绪需要。”**

**最高级的情商，不在于你多会说话，而在于为人处世之中，是否能懂得尊重，懂得换位，懂得分寸，能否站在对方的立场，换位思考。永远是发自内心地尊重他人！**

就像有句话说的：“你希望别人怎么待你，就要先以同样的方式对待别人。”

当你时刻把他人放心上，经常让他人感到舒服，自然也会赢得他人的温柔以待

比起指责更有力的是宽容，让人下不来台的并不是明智的行为，给人留足面子的才是大气之人。

**高情商的人有洞察人心的能力，能够体会他人的情绪及立场，说话做事顾及他人感受。**

**蔡康永说：“我不在乎说话之术，而在意说话之道。我的说话之道，就是把你放在心上。”**
