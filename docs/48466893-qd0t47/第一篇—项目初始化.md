# 第一篇—项目初始化

> 来源：语雀「开源」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/qd0t47/fpgwsudh97thugcg)

## 一、克隆项目

## 代码示例

```bash
git clone https://github.com/element-plus/element-plus.git -b dev
```

由于众所周知的原因，国内访问github往往比较慢，甚至打不开网页，为此我们可以使用一个神器——fastGithub（但好像不维护了），在访问github之前先打开fastGithub。

## 二、安装依赖

参照[Element Plus官方开发指南](https://element-plus.org/zh-CN/guide/dev-guide.html)，安装依赖

```bash
# 安装依赖
pnpm i

# 本地开发
pnpm dev

```

## 2.1、解决安装puppeteer报错

在安装依赖的过程中，还是由于科学上网的原因，很可能会出现：

```bash
ERROR: Failed to set up Chromium r1036745! Set "PUPPETEER_SKIP_DOWNLOAD" env variable to skip download.
│ Error: getaddrinfo ENOENT storage.googleapis.com
│     at GetAddrInfoReqWrap.onlookup [as oncomplete] (node:dns:83:26) {
│   errno: -4058,
│   code: 'ENOENT',
│   syscall: 'getaddrinfo',
│   hostname: 'storage.googleapis.com'
│ }
```

诸如此类关于`puppeteer`的报错，我们不必惊慌，解决办法如下：

第一步：配置npm镜像

```bash
# 淘宝镜像
npm config set registry https://registry.npmmirror.com

# 腾讯镜像
npm config set registry https://mirrors.cloud.tencent.com/npm/

```

第二步：修改根目录`.npmrc`文件，添加如下代码：

```bash
# 对于Puppeteer20.1以上的版本，可以通过以下方式使用国产镜像源：
puppeteer-download-base-url="https://cdn.npmmirror.com/binaries/chrome-for-testing"

# 19以下版本还是原来的方式：
puppeteer-download-host="https://cdn.npmmirror.com/binaries"
```

然后删除`node_modules`重新下载即可，具体可参考[这篇](https://blog.csdn.net/weixin_56307657/article/details/134963129)

## 三、运行

```bash
pnpm dev
```
