# 气场

> 来源：语雀「生活」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/qmvy1p/mahkx6)

## 背景与思路

1.  **人前不做小动作**  
    站有站样，坐有坐样，不抠耳抹鼻，自然专注坚定显气场。
2.  **放慢说话的语速**  
    任何情况下都始终放慢语速，给人的感觉是沉稳，冷静，处事有底气，气场十足强大。
3.  **情绪稳定**  
    气场强大的人在任何情况下都保持着稳定自然的面部情绪，不会随内心变化而变化，纵使内心波澜汹涌。
4.  **眼神自信坚定**  
    坚定的眼神透露着气场的力量。
5.  **待人接物要大气**  
    待人诚恳热情，对人友善尊重，接物大方有分寸，坚持以礼相待。
6.  **少说废话**  
    少说废话，尤其是“嗯，啊，吧，可能，我觉得”等，这些词显得没底气。
