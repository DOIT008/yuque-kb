# 《掌控习惯》

> 来源：语雀「生活」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/qmvy1p/md566a7shpmolwv3)

## ​第一章：点滴变化为何意义重大

结合自己的实践和感悟，越看越觉得，我们平时对习惯、对成长的理解，很多都跑偏了。

我们总是急于求成，总想在某个瞬间突然变成另一个人，无限放大某个决定性时刻，却忽略了量变到质变的过程。正如书里所说：**“人们很容易高估某个决定性时刻的重要性，也很容易低估每天进行微小改进的价值。”**

布雷斯福德在谈到英国自行车队时也说：“把有关骑自行车的整个环节都分解开来，然后把每个分解出来的部分改进1%，在你把各个部分的改进都汇集起来之后，你会发现整体上的显著提高。”

习惯，其实就是自我提高的复利。每天进步1%，长期看力量惊人；可反过来，**“如果一年中你每天以1%的速度退步，你现有的任何东西会降到几乎为零。”**

很多人坚持不下去，就是因为迟迟看不到效果就放弃了。书里说得很真实：**“我们做了一些改变，但总是迟迟不见期待中的效果，于是我们失去了改进的动力，退回到之前惯常的做法。”**

而培养习惯的过程，往往要熬过一段看不见成果的时期：**“有相当长时间是感受不到它的影响的，直到某一天，你突破了临界点，跨入新境界。”**

这其实不只是成长，更是在磨练心性。就像石匠凿石头，前100下都没动静，第101下裂开，并不是最后一下的功劳，而是前面所有坚持的叠加。**“不积跬步，无以至千里，每颗习惯的种子都来自单一的、微小的决定。”**

我们也常常放纵自己，觉得偶尔一次没关系。

但**“只要我们日复一日地重复1%的错误，亦即反复做出不良决策、重复微小的错误，以及为自己的小失误寻找借口，久而久之，我们的小选择会叠加成有害的结果。”**​

一个小小的习惯偏差，时间拉长，人生就会走向完全不同的终点：**“你的日常习惯稍有改变，你的人生道路就会通向一个截然不同的终点。”**

时间久了再回头看，才会明白习惯的分量。**“只有在过了两年、五年或者十年后再回顾时，你才会发现好习惯的价值之高和坏习惯的代价之大令人瞠目结舌。”**

也正应了那句话：起先是我们造成习惯，后来是习惯造成我们。

**“好习惯使时间成为你的盟友，坏习惯使时间成为你的敌人。”**

而成功，从来不是某一次爆发，**“成功是日常习惯累积的产物，而不是一生仅有一次的重大转变的结果。”**

比起盯着结果，更应该关心自己前行的轨迹。你得到的一切，都是日复一日积行成习的结果。

这本书最颠覆我认知的一点，就是\*\*“忘记目标，专注于体系”\*\*。

我们总被教育要设定目标，可书里点得很透：**“目标是关于你想要达到的结果，而体系是涉及导致这些结果的过程。”**

而且很多人没意识到：**“赢家和输家心怀相同的目标。”**

每个运动员都想拿冠军，每个求职者都想拿到offer，目标并不能区分成败，真正拉开差距的是体系。

目标只负责定方向，体系才真正决定你能走多远。

目标导向还有一个很大的问题，就是延迟快乐，总把幸福寄托在下一个里程碑上。而且很容易出现“溜溜球”效应：**“当你所有的努力都集中在一个特定的目标上时，一旦目标实现，推动你努力前行的动力也就失去了依托，这就是为什么许多人在完成预定目标后又恢复了旧习惯。”**

**所以真正长久的方式，不是死盯目标，而是“如果你想要更好的结果，那就别再紧盯着目标不放，而要把精力集中到你的体系建设上。”**

目标只是一瞬间的方向，体系才是决定性的。不求拔高目标，但求落实体系。

再往深一层想，为什么好习惯难坚持、坏习惯难戒掉？

归根到底，**“****坏习惯循环往复，不是因为你不想改变，****而是因为你用来改变的体系存在问题。”**

我们总想着改行为、改结果，**却很少去改导致这一切的根源。修正输入端，输出端自然会修正。**

整本书读下来，最大的感受就是：

别再急于求成，别再只看结果。每天做好微小的改进，搭建稳定的体系，让时间站在自己这一边。

真正的改变，从来不是轰轰烈烈，而是日复一日，水滴石穿。
