## 一、常用快捷键

## 代码示例

```powershell
ctrl+shift+K #删除某一整行
ctrl+x #剪切某一行
ctrl+win+i #文件头部注释
ctrl+win+g #（自后期定义）函数注释
```

## 二、字体

```json
{
  "editor.fontFamily": "fira code regular,微软雅黑", // 第一个是英文字体，第二个是中文字体
  "editor.letterSpacing": 0.5, // 字符间距为0.5个像素
  "editor.lineHeight": 26, //设置编辑器中行高为26像素。
}
```
