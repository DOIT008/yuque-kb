# 环境配置

> 来源：语雀「Python」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/gzq3v8/gpodd190vggcpgyw)

## 一、编辑器

Python最流行的编辑器是JetBrains公司的`Pycharm`，分为[专业版](https://www.aliyundrive.com/drive/home)和[社区版](https://www.jetbrains.com.cn/edu-products/download/download-thanks-pce.html)，对于个人和小型团队而言，社区版已经足够用了。

## 二、Python环境配置

去[Python官网](https://www.python.org/downloads/)下载对应系统的Python软件，安装即可，其实安装的就是**Python解释器**（负责将 Python“翻译”成计算机可以识别的机器语言并执行）。

## 三、注释

-   单行注释：用于对单行代码进行注释，使用`ctrl+/`
-   多行注释：用于对Python文件、类或者方法进行注释，使用`""""""`

## 代码示例

```python
"""
多行注释
"""
```
