## 一、while循环

**特点**：**只要满足条件就会无限循环执行**，直到不满足条件

**适合场景**：不知道要循环多少次时候用

## 代码示例

```python
while 条件:
     操作1
     操作2
     ...
```

举个例子：

```python
# 表白
i=0
while i < 100:
    print('老婆,我爱你！')
    i+=10
    
# 求1到100的和
sum = 0
j = 1
while j <= 100:
    sum += j
    j += 1
print(sum)

# while猜数字
import random
num = random.randint(1, 100) # 随机生成一个1-100的数字
i = 0 # 猜的次数
guess_num = int(input('请输入你猜的数字:')) # 猜的数字
while guess_num != num:
    if guess_num > num:
        print('大了')
    else:
        print('小了')
    guess_num = int(input('请重新输入你猜的数字:'))
    i += 1
else:
    print('恭喜你猜对了')
print('你一共猜了%d次' % i)
```

## 嵌套

```python
while 条件:
     操作1
     操作2
     ...
     while 条件:
           操作1
           操作2
           ...
```

例如

```python
# 嵌套循环 向老婆表白，每次表白送10朵玫瑰花
j = 1 # 1-100
while j <= 100:
    print(f'这是向老婆表白的第{j}天')
    # 每次表白送10朵玫瑰花
    k = 1
    while k <= 10:
        print(f'送给老婆第{k}朵玫瑰花')
        k += 1
    j += 1
print(f'坚持了{j-1}天，向老婆表白结束')

# 九九乘法表

i = 1 #控制有多少行
j = 1 #控制每行有多少列
while i <= 9:
    while j <= i:
        print(str(j) + '*' + str(i) + '=' + str(i * j), end='\t')
        j = j + 1
    print()
    i+=1
    j = 1 #每循环一次，j要重新赋值为1 因为是从1*i开始算的

```

## 二、for循环

**特点**：批量处理

**适用场景**：知道要循环多少次的时候使用

```python
for 临时变量 in 数据集:
    执行代码...
    # 嵌套
    for 临时变量1 in 数据集1
        执行代码1...
```

这上面所谓的“数据集”指的是**序列类型**（内容可以一个个取出的一种类型），内容可以一个个取出的一种类型，包括[**字符串、列表、元组**](https://www.yuque.com/alipayqxigqpgusn/gzq3v8/munmh33cszlirgk4)等。

```python
str = 'itheima is a brand of itcast'
a_count = 0
for i in str:
    if i == 'a':
        a_count += 1
print(f"字符串中包含{a_count}个a") # 字符串中包含4个a
```

九九乘法表


## 三、break

直接**结束整个循环**

```python
for i in range(1,10):
    print()
    print(i,end='\n') # 1
    break
    print("hello") 
```

## 四、continue

**中断所在循环的当次执行，直接进入下次循环，**导致的结果就是`continue`后面的代码**永远不会执行**，例如：

```python
for i in range(1,10):
    print(i,end='\t') # 1	2	3	4	5	6	7	8	9
    continue
    # 永远不可能执行到
    print("hello")
```

> **注意：**
> 
> 1.  两者都可以在`while`和`for`循环中使用，其作用一致
> 2.  在嵌套循环中，`while`和`for`**只作用于所在的循环**，无法对外层循环起作用

综合案例

```python
"""
1. 公司账户余额10000元，给20名员工发工资
2. 员工编号从1到20，编号从1开始，依次领取工资，没人可领取1000元
3. 领取工资时，财务判断员工的自己下份（1-10）随机生成，如果低于5不发工资，换下一位
4. 如果工资发完了，结束发工资
"""
import random
all_money= 10000
yg_count = 20
index  = 1
# 使用for循环
for i in range(1,yg_count+1):
    # 有账户余额才能发工资呀
    if all_money > 0 :
        # 员工绩效
        yg_jx = random.randint(1, 10)
        if yg_jx < 5:
            print(f'员工{i}，绩效分{yg_jx}，低于5，不发工资，下一位')
            continue
        else:
            all_money -= 1000
            print(f'向员工{i}发放工资1000元，账户余额还剩{all_money}元')
    else:
        print("工资发完了，下个月领取吧")
        break

# 使用while循环
while index <= 20:
    # 有账户余额才能发工资呀
    if all_money > 0:
        # 员工绩效
        yg_jx = random.randint(1, 10)
        index += 1
        if yg_jx < 5:
            print(f'员工{index-1}，绩效分{yg_jx}，低于5，不发工资，下一位')
            continue
        else:
            all_money -= 1000
            print(f'向员工{index-1}发放工资1000元，账户余额还剩{all_money}元')
    else:
        print("工资发完了，下个月领取吧")
        break
```
