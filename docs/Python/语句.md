## 1.1、判断语句

## 1.1.1、if-elif-else

### 基础使用

直接看例子不再赘述，**注意缩进！**

## 代码示例

```python
age = 19
height  = 1.75
if age >= 18:
    print("You are an adult.")
    # 嵌套
    if height > 1.8:
        print("You are tall.")
    else:
        print("You are not tall.")
elif age < 10:
    print("You are a minor.")
else:
    print("You are a teenager.")
```

### 且

使用`and`，例如：

```python
if 条件语句1 and 条件语句2 and ...:
    执行语句...
```

### 或

使用`or`，例如：

```python
if 条件语句1 or 条件语句2 or ...:
    执行语句...
```
