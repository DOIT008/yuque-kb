## 一、定义

模块就是一个`.py`文件，里面包含了一些类、变量、函数等，我们可以直接用(导入后)

## 二、导入语法

`from 模块名 from [模块|类|变量|函数|*] [as 别名]`，常用的导入方法如下：

-   `import 模块名`与`import 模块名 as 别名`：前者使用`模块名.功能名`，后者**只能使用**`**别名.功能名**`进行调用
-   `from 模块名 import 类、变量、方法等`与`from 模块名 import 功能名 as 别名`：前者可以直接使用`**功能名**`，后者**只能使用**`**功能名的别名**`进行调用
-   `from 模块名 import *` ：**直接使用模块内的**`**所有功能**`

## 代码示例

```python
import time

print("Hello World") # Hello World
time.sleep(10)
print("我是10秒后出来的") # 我是10秒后出来的

import time as t
print("Hello World") # Hello World
t.sleep(10) # 只能使用t
print("我是10秒后出来的") # 我是10秒后出来的
```

 

```python
from time import sleep
print("Hello World") # Hello World
sleep(10)
print("我是10秒后出来的") # 我是10秒后出来的

from time import sleep as s
print("Hello World") # Hello World
s(10) # 只能使用s
print("我是10秒后出来的") # 我是10秒后出来的
```

 

```python
from time import *
print("Hello World") # Hello World
sleep(10)
print("我是10秒后出来的") # 我是10秒后出来的
time_ns()
# 其他功能名 ...
```

> **注意：**
> 
> 一般导入模块要写在文件头部

## 三、自定义模块

其实你写的**任意一个**`.py`文件都可以当作一个模块，并不像`js`中要使用`export`、`export default`才能导出，例如

```python
def add (a,b):
    return a+b

def sub (a,b):
    return a-b
```

引用

```python
import test_module
print(test_module.add(1, 2)) # 3
print(test_module.sub(1, 2)) # -1
```

如果你想在模块里测试一下你写的代码，可以使用`__main__`，例如：

```python
def add (a,b):
    return a+b

def sub (a,b):
    return a-b

# 主程序 只有当程序作为主程序（直接运行当前文件）运行时才执行,其他情况下(如被其他文件引用)不执行
if __name__ == "__main__":
    print(add(10,20))
    print(sub(30,40))

```

> **注意：**
> 
> 只有当程序作为主程序（直接运行当前文件）运行时才执行,其他情况下(如被其他文件引用)不执行

如果你不想模块中的所有代码都导出可以使用`__all__`来指定哪些内容可以导出，例如：

```python
# __all__ 变量,用于指定模块中可以导出的成员,如果不指定,则默认导出所有成员，即__all__ = ["add","sub"]，下面代码中只导出add函数，也就意味着当使用from math import *时，也只能使用 add 函数
__all__ = ["add"]
def add (a,b):
    return a+b

def sub (a,b):
    return a-b

```

 

```python
from test_module import *
print(add(1, 2)) # 可以使用add
print(sub(1, 2)) # 未解析的引用 'sub'
```

> **注意：**
> 
> `__all__`变量，用于指定模块中可以导出的成员,如果不指定,则**默认导出所有成员**，即`__all__ = ["add","sub"]`，下面代码中只导出`add`函数，也就意味着**当使用**`**from test_module import ***`**时**，也只能使用 `add` 函数，如果使用 `import test_module`也可以访问`sub`

## 四、Python包

## 4.1、定义

**就是一个文件夹**，里面包含了很多python模块，里面还有`__init__.py`文件，是用来管理模块的

## 4.2、如何创建包

使用`pycharm-文件-新建...-Python软件包`创建即可

```python
def sub (a,b):
    return a-b

def mul (a,b):
    return a*b
```

 

```python
def add (a,b):
    return a+b
```

## 4.3、怎么使用包

使用包，其实更多的是使用包里面的模块，那当然要先引入啦

引入方式1——`import 包名.模块名1,包名.模块名2...`

```python
import test_package.my_module, test_package.my_module1
print(test_package.my_module.sub(5,1)) # 4
print(test_package.my_module1.add(5,1)) # 6
```

引入方式2——`from 包名 import 模块名1,模块名2...`

```python
from test_package import my_module, my_module1
print(my_module.sub(5,1)) # 4
print(my_module1.add(5,1)) # 6
```

引入方式3——`from 包名.模块名1 import 功能名1,功能名2...`

```python
from test_package.my_module import sub,mul
from test_package.my_module1 import add
print(sub(5,1)) # 4
print(mul(5,2)) # 10
print(add(5,1)) # 6
```

引入方式4——`import 包名 import *`

```python
from test_package import *
print(my_module.sub(5,1))
print(my_module1.add(5,1))
```

## 4.4、\_\_all\_\_

`__init__.py`中的变量`__all__`作用跟模块中的一样，只不过这里控制的是模块

### 4.5.2、举例

#### pyechart

[pyechart](https://05x-docs.pyecharts.org/#/)是`echarts`的python版本，主要用来进行绘制一些图表，下面先以这个为例进行演示：

安装pyechart包

```powershell
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple pyecharts
```

  

```python
# 引入pyecharts包中的Line
from pyecharts.charts import Line
from pyecharts.options import TitleOpts, LegendOpts, ToolboxOpts,VisualMapOpts

# 创建折线图对象
line = Line()
# 添加数据
# 添加x轴数据
line.add_xaxis(["衬衫", "羊毛衫", "雪纺衫", "裤子", "高跟鞋", "袜子"])
# 添加y轴数据
line.add_yaxis("商家A", [5, 20, 36, 10, 75, 90])

# 全局配置
line.set_global_opts(
    # 设置标题和副标题
    title_opts=TitleOpts(title="商品信息", subtitle="销量"),
    # 设置图例
    legend_opts= LegendOpts(is_show=True, pos_left='center', orient='vertical'),
    # 设置工具箱
    toolbox_opts=ToolboxOpts(),
    # 设置视觉映射
    visualmap_opts=VisualMapOpts(is_show=True),
)
# 渲染折线图
line.render()
```

运行上述代码会在`pyecharts.py`同级目录下生成一个`render.html`文件，用浏览器打开即可
