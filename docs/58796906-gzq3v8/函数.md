## 代码示例

```python
def 函数名(形参1,形参2...):
    函数体（要做的事情）
    # 如果有返回值，则return
    return <返回值>
```

## 调用

```python
函数名(参数)
```

## 返回值：None

如果函数中没有使用`return` 返回数据，那么函数也是有返回值的，返回的是`None`，表示空，其类型是`<class 'NoneType'>`

> **注意：**
> 
> 1.  在`if`语句中`None`等同于`False`
> 2.  一般用于在函数中主动返回`None`，配置`if`语句做处理

## 返回多个值

函数可以`return`多个返回值，返回值之间用**逗号**隔开，如果用变量接收返回值，也是**用逗号隔开**

```python
def test_return(a,b):
    return a+b,a-b,a*b,a/b
# 变量接收用逗号
jia,jian,cheng,chu = test_return(10,5)
# 打印
print(jia,jian,cheng,chu) # 15 5 50 2.0
```

## 参数

### 位置参数

按照参数定义的顺序传参

```python
def user_info(name,age,gender):
    print(f'您的名字是{name},年龄是{age}，性别是{gender}')

user_info('小明',18,'男') # 您的名字是小明,年龄是18，性别是男
```

### 关键字参数

通过`key=value`的形式传参，可以不按照参数的定义顺序

```python
def user_info(name,age,gender):
    print(f'您的名字是{name},年龄是{age}，性别是{gender}')
user_info(age=18,name='小明',gender='男') # 您的名字是小明,年龄是18，性别是男
user_info(gender='男',name='小明',age=18) # 您的名字是小明,年龄是18，性别是男
```

### 混合参数

混合参数，位置参数和关键字参数混合使用，**位置参数必须在关键字参数之前**

```python
def user_info(name,age,gender):
    print(f'您的名字是{name},年龄是{age}，性别是{gender}')
user_info('小明',age=18,gender='男') # 您的名字是小明,年龄是18，性别是男
```

### 默认值

在定义函数时，给参数设置一个默认值，如果调用函数时没有传递该参数，则使用默认值，另外带**默认值的参数必须是在最后面**

```python
def user_info2(name,age,gender='男'):
    print(f'您的名字是{name},年龄是{age}，性别是{gender}')

user_info2('小明',18) # 您的名字是小明,年龄是18，性别是男
user_info2('小红',19,'女') # 您的名字是小红,年龄是19，性别是女

# 多默认值
def user_info3(name,age=20,gender='男'):
    print(f'您的名字是{name},年龄是{age}，性别是{gender}')
    
user_info3('小明') # 您的名字是小明,年龄是20，性别是男

# 错误写法
def user_info4(name,age=20,gender):
    print(f'您的名字是{name},年龄是{age}，性别是{gender}')
user_info4('小明',21,'男') # 报错
```

### 不定长参数

#### 位置不定长

语法：`def 函数(*args):`

在调用的时候传递的参数被收集在`args`里，这里的`args`是一个**元组**，其实跟`js`中的`arguments`差不多，例如：

```python
def user_info(*args):
    print(args)
user_info('小明',18,'男') # ('小明', 18, '男')
user_info('小明') # ('小明',)
```

#### 关键字不定长

语法：`def 函数(**kwargs):`，在实际调用的时候参数必须以`key=value`的形式传参，这路`kwargs`是**字典**

```python
def user_info(**kwargs):
    print(kwargs)
user_info(name='小明',age=18,gender='男') # {'name': '小明', 'age': 18, 'gender': '男'}
user_info(name='小红') # {'name': '小红'}
```

## 注释

起到一个解释说明的作用

```python
def add (x,y):
    """
    两数相加
    :param x: 加数x
    :param y: 加数y
    :return: z
    """
    z = x + y
    return z
# 调用
result = add(10, 20)
print(result) # 30
```

> **注意：**
> 
> 1.  在函数体中使用`"""+回车`，编辑器自动会帮我们补全注释

## 函数嵌套调用

其实就是在某个函数内调用另一个函数

```python
def func1():
    print("func1")

def func2():
    print("func2")
    # 在func2中调用func1函数
    func1()
    print("func3")
func2()
#  输出---
# func2
# func1
# func3

```

## 作用域

变量**作用域**指的是变量的作用范围，其实就是变量在哪里能被访问得到哪里访问不到。主要分为：

1.  **全局变量**：在任何地方都能访问到的变量
2.  **局部变量**：一般定义在函数体内部的变量就是局部变量

那么我想在函数中修改全局变量怎么办，**不能直接修改**，因为这样的话相当于在函数内部定义了一个跟外部全局变量一样的局部变量，但可以**使用关键字**`**global**`就可以了，例如：

```python
# 全局变量num
num = 300

def test_a():
    # 局部变量num
    num = 100
    print(f"当前num值是{num}") # 当前num值是100
test_a()
print(num) # 访问的是全局变量 300

def test_b():
    # 设置内部变量num为全局变量
    global num
    # 修改全局变量
    num = 99
test_b()
print(num) # 99
```

## 匿名函数

使用`lambda`定义匿名函数，具体语法是`lambda [arg1 [,arg2,...argn]]:expression(一行代码)`，举个例子：

```python
# 返回值就是表达式的结果
sum = lambda x,y:x+y
print(sum(1,2)) # 3
 # 相当于
def sum (x,y):
    return x + y
print(sum(1,2)) # 3

# 不传参数
greeting = lambda :print("hello")
greeting() # hello
```

> **使用场景：**
> 
> -   用于临时构建一个函数，**只用一次的场景**
> -   匿名函数的函数体中**只能写一行代码**，如果要写多行代码，不要用`lambda`函数，必须使用`def`具名函数

## 取钱例子

```python
money = 5000000
name= input("请输入您的名字: ")

# 主函数
def main():
    print(f'{name}，您好，欢迎来到黑马银行ATM，请选择操作：')
    print('查询余额【输入1】')
    print('存款【输入2】')
    print('取款【输入3】')
    print('退出系统【输入4】')
    choice = int(input('请输入您的选择：'))
    if choice == 1:
        query_balance()
    elif choice == 2:
        save_money()
    elif choice == 3:
        withdraw_money()

# 查询余额
def query_balance():
    """
    查询余额
    :return:
    """
    print(f"{name}，您好，您的余额剩余{money}元")
    main()

# 存款
def save_money():
    """
    存款
    :return:
    """
    global money
    money+=50000
    print(f"{name}，您好，您的存款50000元成功")
    print(f"{name}，您好，您的余额剩余{money}元")
    main()

# 取款
def withdraw_money():
    """
    取款
    :return:
    """
    global money
    money-=50000
    print(f"{name}，您好，您的取款50000元成功")
    print(f"{name}，您好，您的余额剩余{money}元")
    main()

# 执行
main()
```
