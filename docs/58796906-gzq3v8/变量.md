## 一、字面量与变量

## 1.1、分类

其实就是数据类型，在Python中有**7种数据类型**，分别是数字、字符串，列表，元组，集合和字典。

### 1.1.1、数字

-   整数（int）：如`10`，`20`，`-10`等
-   浮点数（float）： `-10.0`，`10.13`，`10.4`等
-   复数：如`5+2j`，以`j`结尾的表示复数

### 1.1.2、字符串

#### 定义

`str`任意数量的字符组成的串，跟JS中的字符串一样，不在赘述。

定义字符串的方式：除了`单引号(')`，`双引号(")`还有`三引号(""")`，举个例子：

## 代码示例

```python
"""
字符串定义
"""
# 单引号
a = 'hello'
print(a)
# 双引号
b = "world"
print(b)

# 三引号
c = """
    hello world
"""
print(c)

# 可以用\解除引号的效用，变成普通字符串的一部分
d = 'I\'m a boy'
print(d)
```

对于**引号的嵌套有三种解决方式**：

1.  单引号内嵌套双引号
2.  双引号内嵌套单引号
3.  使用`\`解除引号的效用（如上图）

#### 拼接

直接用`+`即可，但需要注意的是：仅仅支持字符串之间的拼接，否则会报错

```python
e = 'hello'
f = 'world'
g  = 12

print(e +','+ f + g) # can only concatenate str (not "int") to str
```

但如果我想拼接其他类型的数据呢？可以使用`str()`先将其转化为字符串再进行拼接

### 1.1.3、布尔

#### 基础

在Python中布尔值只有两个`True`和`False`，所对应的比较运算符分别是`==`、`!=`、`>`、`<`、`>=`、`<=`，此外还有取非运算符`not`

```python
name1 = "John"
name2 = "John1"
print(name1==name2) # False
a =10
b = 5
print(a>b) # True

# 取非运算符
flag = True
flag1 = False
print(flag1== (not flag))  # True
```

  

> **注意：**
> 
> Python中不等只有`!=`、等于只有`==`，跟JS不一样！

## 1.2、标识符/变量

在Python中定义变量使用`变量名=变量值`进行定义，例如

```python
# 定义变量
count = 10
str = "hello world"
```

而Python中标识符其实就是变量、类或函数等的名字。

### 1.2.1、命名规则

-   **内容限定**：名字只能由**英文、中文（不推荐）、数字（不能放在开头）、下划线（\_）**组成，其他任何内容都不被允许
-   **大小写敏感**：同一个单词，大小写不一样就是不同的变量
-   **不能使用关键字**：不再赘述

## 1.3、运算符

除了常见的`+`、`-`、`*`、`/`、`%（取余）`之外，还有两个：

-   **//（取整除）：**返回商的整数部分，比如9//2 返回4，9.0/2.0返回4.0
-   **\*\*（指数）**：a\*\*b为10的3次方，返回1000

```python
# 指数运算
a = 2**3
b= 2**3**2
c = 2**-3
print(a) # 8
print(b) # 512
print(c) # -0.125

#  取整除
d = 10//3
e = 10//3.0
f = 10.0//3.0
g = 10//11
print(d) # 3
print(e) # 3.0
print(f) # 3.0
print(g) # 0

```

**复合运算符：**

1.  `+=`：例如a += b等效于a = a+b
2.  `-=`：例如a -= b等效于a = a-b
3.  `*=`：例如a \*= b等效于a = a\*b
4.  `/=`：例如a /= b等效于a = a/b
5.  `%=`：例如a %= b等效于a = a%b
6.  `//=`：例如a //= b等效于a = a//b
7.  `**=`：例如a \*\*= b等效于a = a\*\*b
