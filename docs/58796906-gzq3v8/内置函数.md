## 一、print()

输出内容，通常用来打印日志

### 1.1、基本用法

## 代码示例

```python
print('hello world')
```

### 1.2、格式化输出

**语法**：`"占位符" % 变量或表达式` 表示将变量或表达式“放入”占位符的地方

#### 1.2.1、常见的格式化符号

::: tip
[object Object]
:::

例如：

```python
# 字符串格式化
home_address = '河南省许昌市'
age = 20
height = 1.75
# 单个占位符
print('我的家住在%s' % home_address) # 我的家住在河南省许昌市
# 多个占位符  %s代表字符串，%d代表整数，%f代表浮点数 
print('我的家住在%s,我今年%d岁了,身高%f米' % (home_address, age, height)) # 我的家住在河南省许昌市,我今年20岁了,身高1.750000米
# 等效
print('我的家住在%s,我今年%s岁了,身高%s米' % (home_address, age, height)) 
```

> **注意**：
> 
> 多个变量占位，变量（或表达式）要用括号括起来，并按照占位顺序填入

#### 1.2.2、格式化符号辅助指令

通过以上可以发现字符串中的浮点数小数点后面有好多位，这肯定不是我们想要的，那么如何进行精度控制呢？当然有！

在Python中对字符串中的浮点数进行精度控制主要是使用`m.nf%`进行设置的，**其中**`**m**`**控制数字的宽度，设置的宽度小于自身则**`**m**`**不生效****（不常用）****，**`**n**`**控制保留几位小数，会进行四舍五入，例如：**

```python
height = 1.75
print('我的身高是： %f米' % height ) #我的身高是： 1.750000米
print('(宽度限制为5，保留3位小数)我的身高是： %5.3f米' % height ) # (宽度限制为5，保留3位小数)我的身高是： 1.750米
print('(宽度限制为4，保留3位小数)我的身高是： %4.3f米' % height ) # (宽度限制为4，保留3位小数)我的身高是： 1.750米
print('(宽度限制为6，保留3位小数)我的身高是： %6.3f米' % height ) # (宽度限制为6，保留3位小数)我的身高是：  1.750米
print('(宽度限制为3，保留1位小数)我的身高是： %3.1f米' % height ) # (宽度限制为3，保留1位小数)我的身高是： 1.8米
print('(保留1位小数)我的身高是： %.1f米' % height ) # (保留1位小数)我的身高是： 1.8米
```

如果`m`设置的比较大，就会用`空格`填充，例如：

```python
print('我的年龄是 %5d' % age) #我的年龄是    20
```

#### 1.2.3、快速格式化（推荐）

使用`f"内容{变量或表达式}"`的方式进行快速格式化，这个方法也不会有浮点数精度的问题，不管是啥都是原样输出，例如

```python
home_address = '河南省许昌市'
age = 20
height = 1.75
print(f'我的家住在{home_address},我今年{age}岁了,我的身高是{height}米') 
# 我的家住在河南省许昌市,我今年20岁了,我的身高是1.75米
```

### 1.3、不换行

`print`会自动在行末加上回车, **如果不需回车，只需在** `**print**`**语句的结尾添加一个逗号**`**,**`**并设置分隔符参数** `**end**`**：** 例如：

```python
for i in range(0,3):
    print(i, end = '' ) # 012

for i in range(10):
    print(i, end=' ') # 0 1 2
    
for i in range(10):
    print(i, end='\t') # 0  1  2

```

### 1.4、换行

使用`\n`可以在打印的字符串中进行换行，例如：

```python
 print('欢迎来到黑马程序员！\n请出示您的健康码及72小时内核酸检测阴性证明')
# 欢迎来到黑马程序员！
# 请出示您的健康码及72小时内核酸检测阴性证明
```

## 二、range()

返回的是一个可迭代对象（**类型是对象**），而不是列表类型，**一般用在for循环中**

### 2.1、语法

```plain
range(stop)
range(start, stop[, step])
```

### 2.2、参数说明

-   **start**: 计数从 `start` 开始。默认是从 `0` 开始。例如 `range(5)` 等价于 **range(0， 5)**
-   **stop**: 计数到 `stop` 结束，**但不包括** `**stop**`。例如：`range(0,5)` 是 `[0, 1, 2, 3, 4]` 没有 `5`
-   **step**：步长，默认为 **1**。例如：`range(0,5)` 等价于 `range(0, 5, 1)`，当然也可以为负值如`-1`，这样就会递减。

## 三、input()

### 3.1、语法

```python
input('提示内容')
```

然后使用变量接收输入的内容也就是`变量=input('提示内容')`，例如：

```python
name = input("请输入您的名字：")  # 请输入您的名字：张三
print("你好,%s" % name) # 你好,张三

num = input("请输入一个数字：") # 请输入一个数字：122.33
print('您输入的的内容类型是： %s' % type(num)) # 您输入的的内容类型是： <class 'str'>
```

> **注意：**
> 
> 1.  无论你输入的是啥，获取到的**永远都是字符串**
> 2.  键盘上的特殊键位如`ctrl`、`shift`等输入无效

## 四、数据类型转换

### 4.1、int()

将`x`转化成整数，遵循以下规则：

1.  `x`是整数的数字字符串：例如`'123'`，`'456'`正常转
2.  `x`是浮点数字符串：例如`'123.45'`，`'123.78'`报错
3.  `x`是非数字字符串：例如`hello world`报错
4.  `x`是浮点数，直接舍弃小数部分（丢失精度），正常转

```python
# 字符串整数转int
str_num = '123'
# 字符串浮点数转int 报错
str_num2 = '123.45'
# 浮点数转int 直接舍弃小数部分
float_num3 = 123.45
float_num4 = 123.99

int_num = int(str_num)
int_num2 = int(str_num2)
int_num3 = int(float_num3)
int_num4 = int(float_num4)

print(int_num) # 123
print(str_num2) # 报错
print(int_num3) # 123
print(int_num3) # 123
```

### 4.2、float(x)

将`x`转化为浮点数，这里的`x`可以是数字字符串，也可是数字

```python
int_num = 123
str2= '123'

# 整数转浮点数
float_num = float(int_num) 

# 字符串转浮点数
float_num2 = float(str2)

print(float_num,float_num2) # 123.0 123.0
```

### 4.3、str(x)

将`x`对象转化为字符串，实际上**任何数据类型**都可以转化为字符串，不再举例

## 五、type(x)

使用`type(变量/数据)`即可，例如：

```python
a = 120
b = 123.456
c = True
d = False
e = 'hello'
print(type(a), type(b), type(c), type(d), type(e))
# <class 'int'> <class 'float'> <class 'bool'> <class 'bool'> <class 'str'>
```
