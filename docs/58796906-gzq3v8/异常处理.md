## 一、语法

## 代码示例

```python
try:
# 可能要发生异常的语句
except[异常 as 别名：]
# 出现异常的准备手段
[else:]
# 未出现异常时应做的事情
[finally:] 
# 不管出不出现异常都会做的事情
```

### 1.1、基本用法

```python
# 基本用法，try-except
try:
    # 尝试打开文件
    f = open('test.txt', 'r',encoding='utf-8')
except:
    # 如果打开文件失败，则创建一个新的文件
    f = open('test.txt', 'w', encoding='utf-8')
```

### 1.2、捕获指定异常

```python
# 捕获NameError异常
try:
    print(name)
except NameError as e:
    print("name未定义",e)

# 捕获ZeroDivisionError异常
try:
    print(100/0)
except ZeroDivisionError as e:
    print("ZeroDivisionError",e) # division by zero
```

### 1.3、捕获多个异常

```python
try:
    # print(100/0)
    print(name)
except (ZeroDivisionError,NameError) as e:
    print("捕获到了多个异常",e)
```

## 二、捕获所有异常

代码中的异常是多种多样的，如果我们想捕获所有异常可以使用`except`或者`except Exception as e（推荐）`

```python
try:
    print(100 / 0)
except Exception as e:
    print("捕获到所有异常", e)
```

## 三、完整用法

```python
try:
    print(100 / 1)
except Exception as e:
    print("捕获到所有异常", e)
else:
    print("没有发生异常")
finally:
    print("无论是否有异常都会执行")
```

## 四、异常的传递性

```python
# 异常的传递性
def fun1():
    print("fun1函数开始")
    print(100 / 0)
    print("fun1函数结束")

def fun2():
    print("fun2函数开始")
    fun1()
    print("fun2函数结束")

def main():
    try:
        fun2()
    except Exception as e:
        print("main函数捕获到异常", e) # main函数捕获到异常 division by zero

main()
```

## 五、主动抛出异常
