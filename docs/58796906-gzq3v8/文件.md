## 一、文件编码

文件是怎么被电脑识别并存储到电脑上的呢，这就涉及到文件的**编码（密码本）技术**——将文件内容翻译成0和1进行存入。比如常见的：**UTF-8（最常用）**、GBK、Big-5等，不同的编码翻译的结果也不一样

## 二、文件操作

### 2.1、打开

#### 2.1.1、一般用法

**语法**：`open(name,mode,buffering,encoding...)`，表示**打开一个已经存在的文件或者创建一个新文件**

-   name：是要打开的目标文件名的字符串（可以包含文件所在的具体路径）
-   mode：设置打开文件的模式（访问模式）：只读（r）、写入（w）、追加(a)等
-   buffering：略
-   encoding：编码格式（**推荐使用UTF-8**）

模式 | 描述
--- | ---
t | 文本模式 (默认)。
x | 写模式，新建一个文件，如果该文件已存在则会报错。
b | 二进制模式。
+ | 打开一个文件进行更新(可读可写)。
U | 通用换行模式（不推荐）。
r | 以只读方式打开文件。文件的指针将会放在文件的开头。这是默认模式。
rb | 以二进制格式打开一个文件用于只读。文件指针将会放在文件的开头。这是默认模式。一般用于非文本文件如图片等。
r+ | 打开一个文件用于读写。文件指针将会放在文件的开头。
rb+ | 以二进制格式打开一个文件用于读写。文件指针将会放在文件的开头。一般用于非文本文件如图片等。
w | 打开一个文件只用于写入。如果该文件已存在则打开文件，并从开头开始编辑，即原有内容会被删除。如果该文件不存在，创建新文件。
wb | 以二进制格式打开一个文件只用于写入。如果该文件已存在则打开文件，并从开头开始编辑，即原有内容会被删除。如果该文件不存在，创建新文件。一般用于非文本文件如图片等。
w+ | 打开一个文件用于读写。如果该文件已存在则打开文件，并从开头开始编辑，即原有内容会被删除。如果该文件不存在，创建新文件。
wb+ | 以二进制格式打开一个文件用于读写。如果该文件已存在则打开文件，并从开头开始编辑，即原有内容会被删除。如果该文件不存在，创建新文件。一般用于非文本文件如图片等。
a | 打开一个文件用于追加。如果该文件已存在，文件指针将会放在文件的结尾。也就是说，新的内容将会被写入到已有内容之后。如果该文件不存在，创建新文件进行写入。
ab | 以二进制格式打开一个文件用于追加。如果该文件已存在，文件指针将会放在文件的结尾。也就是说，新的内容将会被写入到已有内容之后。如果该文件不存在，创建新文件进行写入。
a+ | 打开一个文件用于读写。如果该文件已存在，文件指针将会放在文件的结尾。文件打开时会是追加模式。如果该文件不存在，创建新文件用于读写。
ab+ | 以二进制格式打开一个文件用于追加。如果该文件已存在，文件指针将会放在文件的结尾。如果该文件不存在，创建新文件用于读写。

### 2.5、写入/追加

写入文件是在打开文件的基础上的（毕竟要先打开才能写入呀），所以写入的操作可以概括为：`打开文件（不管有没有这个文件）--写入--flush()/close()`

1.  **打开**：使用`f=open(文件路径,'w或者a',encoding='utf-8')`
2.  **写入**：`f.write(内容)`，执行这个操作内容并未真正写入文件，而是会积攒在程序的内存中，称之为**缓冲区**
3.  **刷新**：`f.flush()`，当调用`flush`的时候，内容会真正写入文件，这样做是避免频繁的操作硬盘，导致效率下降（攒一堆，一次性写磁盘），`f.close()`：内置`flush`也会写入磁盘

```python
f = open('C:/Users/Administrator/Desktop/test2.txt', 'w', encoding='utf-8')
f.write('这是一个测试文本，用于测试Python脚本是否能够正确地读取和写入文件\n') # 写入一些内容
f.write('再次写入一些内容') # 写入一些内容
# f.flush() # 刷新缓冲区，将缓冲区的内容写入文件
f.close()
```

 

```python
# 我有一个小毛驴
f = open('C:/Users/Administrator/Desktop/test.txt', 'a', encoding='utf-8')
f.write('，从来也不骑') # 写入一些内容
f.write('，哈哈哈哈') # 写入一些内容
f.close() # 我有一个小毛驴，从来也不骑，哈哈哈哈
```

> **注意：**
> 
> 1.  跟读取相似，每调用一次写入方法`write()`会是**从上一次写入的结尾处开始写入**
> 2.  w模式：文件不存在会创建新文件，**文件存在，会清空原有内容**
> 3.  a模式：如果文件不存在会创建新文件，**文件存在，会在原有内容的基础上写入新内容**
> 4.  可使用`\n`进行换行

综合案例

![image.png](/images/6e9273340248822a.png)

要求：

-   读取文件
-   将文件写出到bil1.txt.bak文件作为备份
-   同时，将文件内标记为测试的数据行丢弃

```python
 # 打开一个文件，读取其中的所有行，并将其存储在一个列表中
f = open('C:/Users/Administrator/Desktop/test.txt', 'r', encoding='utf-8')
# 打开一个备份文件，用于存储过滤后的数据
f_bak = open('C:/Users/Administrator/Desktop/test.txt.bak', 'w', encoding='utf-8')
for line in f:
    # 去掉每一行的首尾空白符换行符
    line = line.strip()
    # 将每一行的内容按逗号分隔，并存储在一个列表中
    line_arr = line.split(',')
    # 判断列表中的元素是否包含"测试"字符串，如果包含则跳过该行，否则将其写入备份文件
    if line_arr[4] =='测试':
        continue
    else:
        f_bak.write(line+'\n')
f_bak.close()
f.close()
```
