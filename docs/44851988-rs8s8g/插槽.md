### 定义

插槽说白了就是一个“坑位”能够让你在组件标签内部插入一些内容，而这些内容可以被插入到这个“坑位”中，其实Vue3中的插槽和Vue2.x中的插槽差不多，分类也一样，只不过写法可能有些差别，但其实也没那么大啦，现在就举个例子 说明一下就行了，毕竟这个东西已经比较熟悉了。

### 默认插槽

其实就相当于特殊具名插槽，只不过这个名字是`default`，下面举个例子：

## 代码示例

```vue
// Son.vue
<template>
    <slot></slot>
  <!-- 相当于 -->
  <!-- <slot name="default"></slot> -->
</template>

```

 

```vue
 <Son>
      <template>
        <div>
          <h1>张三</h1>
        </div>
      </template>
    </Son>
```

上面`Son`标签内部的`template`标签内容就会被插入到`<slot name="default"></slot>`的位置，以起到扩展组件的作用。

### 具名插槽

具名插槽，顾名思义就是有名字的插槽，和默认插槽相比，**你可以将内容查入到特定的位置**：

```vue
// Son.vue
<template>
  <slot name="kslot"></slot>
</template>
```

 

```vue
 <Son>
   <template v-slot:kslot>
			<div>我是来自具名插槽kslot</div>
   </template>
</Son>
```

在组件内部通过`slot`标签上的`name`属性指明当前的插槽名字，在使用组件的时候要在`template`标签上使用`v-slot:插槽名`进行注明（不能写在已有的元素标签上）。

### 作用域插槽

对于作用域插槽，个人认为就是将组件内部（也就是说数据来源于子组件）的数据通过`v-bind`传递给父组件，然后在父组件内部整理好数据后再在组件内部`slot`标签处展示，例如还是上面的`Son.vue`组件：

```vue
// Son.vue
<template>
  <button>改变provide的数据</button>
  <!-- 通过v-bind将组件内部的数据传递给父组件，在父组件中整理好内容并分发到这个slot标签所在的位置 -->
  <slot :user="user" :list="list"></slot>
<!--   <slot :user="user" :list="list" name="scopeSlot" ></slot> -->
</template>

<script>
import {  reactive, toRefs } from "vue";
export default {
  name: "son",
  setup(props, { emit }) {
    const sonData = reactive({
      user: {
        firstName: "John",
        lastName: "Smith",
      },
      list: ["张三", "李四", "王五", "赵六"],
    });
    return {
      ...toRefs(sonData),
    };
  },
};
</script>
```

在Father.vue中，整理内容

```vue
// Father.vue

<Son>
  <!-- 这里的user就是通过Son组件内部的user传递过来的对象，没写name默认就是default -->
  <template #default ="{ user, list }">
    <div class="slot-container1">
      {{ user.lastName }}
      <div v-for="(item, index) in list" :key="index">{{ item }}</div>
    </div>
  </template>

    
// 带名字的具名插槽scopeSlot
// <template #scopeSlot ="{ user, list }">
//     <div class="slot-container1">
//       {{ user.lastName }}
//       <div v-for="(item, index) in list" :key="index">{{ item }}</div>
//     </div>
//   </template>
  
</Son>
```

### 在setup内访问插槽内容

其实主要还是用到了setup函数的两个参数`props`和上下文`ctx`：

1.  props：一个对象，里面包含了所有从父组件传递过来的数据，通过`props.xx`访问
2.  ctx：上下文对象，里面包含了`emit（抛出自定义事件可用）`，`slots(插槽相关)`，`attrs（属性相关）`

这样访问插槽内容：

```vue
<template>
  <div>
    <div>{{ msg }}</div>
    <slot></slot>
    <slot name="KSlot"></slot>
  </div>
</template>

<script>
export default {
  props: ["msg"],
  setup(props, ctx) {
    console.log(props.msg, ctx.slots.default()[0].children); //, 访问默认插槽
    console.log(ctx.slots.KSlot()[0].children); // 访问具名插槽KSlot的内容
    return {};
  },
};
</script>
```
