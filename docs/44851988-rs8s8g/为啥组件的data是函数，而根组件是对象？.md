# 为啥组件的data是函数，而根组件是对象？

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/vuf8mc)

## 背景与思路

因为对于我们自定义的组件而言，他可能**有多个实例**，如果其data选项是一个对象，就会导致这**多个实例共用这一个数据对象**，这样就会造成数据污染(比如在一个实例中我们修改了某个数据，其他数实例的该数据也会发生变化，这肯定不是我们想要的)，如果是函数形式，那么每次创建这个实例的时候都会执行一下这个data函数，每次都会创建新的对象，这样每个对象都是相互独立的，所以就不会存在这种问题。

**而对于根实例而言**，**其实例只有一个**，所以没必要设置成函数的形式。

  

> 在源码中，在数据初始化的时候都会执行initData方法，里面有一个判断，如果是一般的组件，因为没有实例，该方法会检测data选项的类型，如果是根组件，他有实例会把实例本身穿进去，从而规避了检测。
