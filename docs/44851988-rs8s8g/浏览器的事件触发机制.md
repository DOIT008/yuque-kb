## 三个阶段

浏览器的事件触发分为三个阶段：捕获阶段--目标阶段--冒泡阶段

-   **捕获阶段**：事件从根节点出发一直向下寻找，直到找到目标节点
-   **目标阶段**：在该阶段触发我们真正点击元素上的事件
-   **冒泡阶段**：事件从目标节点出发向上，一层层父节点上的事件，一直到根节点**（也就是一般情况下事件真正触发的顺序）**

但是对于经典的层层嵌套的元素的点击事件，究竟是如何触发的（先执行谁后执行谁），这**个跟我们开发人员的写法**有关，**绑定事件时通过addEventListener函数，它有三个参数，第三个参数若是true，则表示采用事件捕获，若是false（默认），则表示采用事件冒泡。**

JS代码

```js
// 事件冒泡，默认第三个参数是false
let con = document.querySelector('.container');
let con1 = document.querySelector('.container1');
let con2 = document.querySelector('.container2');
let con3 = document.querySelector('.container3');
con.addEventListener('click', () => {
  console.log(0);
});
con1.addEventListener('click', () => {
  console.log(1);
});
con3.addEventListener('click', () => {
  console.log(3);
});
con2.addEventListener('click', () => {
  console.log(2);
});// 3,2,1,0

// 事件捕获
con.addEventListener('click', () => {
  console.log(0);
},true);
con1.addEventListener('click', () => {
  console.log(1);
},true);
con3.addEventListener('click', () => {
  console.log(3);
},true);
con2.addEventListener('click', () => {
  console.log(2);
},true);// 0,1,2,3

```
