## 一、规则

以前我们在用公共组件的时候，流程是引入-注册-使用，现在Nuxt中不是这样了，你写完就可以用了，只不过要写在根目录的`components`文件夹下：

## 代码示例

```latex
-|components
---|TheHeader.vue
---|TheContent.vue
---|TheFooter.vue
---|list/
-----|ListItem.vue
---|LazyButton.vue  //懒加载的组件

```

使用

```vue
<template>
  <div>
    <h3>这里是parent/index.vue页面,在nuxt-child组件中默认展示的内容</h3>
    <the-header></the-header>
    <list-item></list-item>
  </div>
</template>

<script>
import ListItem from '~/components/list/ListItem.vue'
import TheHeader from '~/components/TheHeader.vue'
export default {
  components: { TheHeader, ListItem },
}
</script>

<style lang="scss" scoped></style>

```

你会发现在你写`<the-header>`的时候，nuxt会自动的进行引入和注册，很神奇！

不过有个小问题，就是同一个组件以不同的方式在使用的时候会出现重复导入注册的情况🤣🤣🤣:

```vue
<template>
  <div>
    <h3>这里是parent/index.vue页面,在nuxt-child组件中默认展示的内容</h3>
    <the-header></the-header>
    // 不同的使用方式
    <list-item></list-item>
    // 驼峰法
    <ListItem/>
  </div>
</template>

<script>
 // 第一次
import ListItem from '~/components/list/ListItem.vue'
import TheHeader from '~/components/TheHeader.vue'
// 第二次
import ListItem from '../../components/list/ListItem.vue'
export default {
  components: { TheHeader, ListItem,ListItem },
}
</script>

<style lang="scss" scoped></style>
```

## 二、组件懒加载

如果在组件名称前加上`Lazy`前缀，那么这个组件就变成了懒加载的组件，就可以实现按需加载，优化打包大小

```vue
<template>
  <div>
    <h3>这里是parent/index.vue页面,在nuxt-child组件中默认展示的内容</h3>
    <the-header></the-header>
    <list-item></list-item>
    <LazyButton v-if="showBtn"></LazyButton>
    <el-button type="primary" @click="handleBtnClick"
      >显示/隐藏LazyButton组件</el-button
    >
  </div>
</template>

<script>
import ListItem from '~/components/list/ListItem.vue'
import TheHeader from '~/components/TheHeader.vue'
import LazyButton from '../../components/LazyButton.vue'
export default {
  data() {
    return {
      showBtn: false,
    }
  },
  methods: {
    handleBtnClick() {
      this.showBtn = !this.showBtn
    },
  },
  components: { TheHeader, ListItem, LazyButton },
}
</script>

<style lang="scss" scoped></style>

```
