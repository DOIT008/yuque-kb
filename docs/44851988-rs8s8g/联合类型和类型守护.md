## 定义

光看名字就知道联合类型顾名思义就是说一个变量可能有多种类型吧，类型和类型之间一般用`|`进行分割，

例如：

## 代码示例

```ts
interface Waiter {
  anjiao: boolean;
  say();
}
interface Teacher {
  spa: boolean;
  skill();
}

function judgeWho(person:Waiter|Teacher){}
```

## 类型守护

所谓类型守护，指的是对于某个 变量当类型不确定的时候，进行的判断,通常有三种方式

### 使用in操作符

判断某个属性是否在某个对象中

```ts
interface Waiter {
  anjiao: boolean;
  say();
}
interface Teacher {
  spa: boolean;
  skill();
}

// 使用in操作符
function judgeWho(person: Waiter | Teacher) {
  if ("anjiao" in person) {
    (person as Waiter).say();
  } else if ("spa" in person) {
    (person as Teacher).skill();
  }
}
```

### 使用typeof操作符

判断数据类型，一般对基础类型使用这个操作符

```ts
function add(a: string | number, b: string | number) {
  if (typeof a === "string" || typeof b === "string") {
    return `${a}${b}`;
  } else {
    return a + b;
  }
}
```

### 使用instanceof操作符

通常看一下某个对象是否是某个类的实例

```ts
class Animal {
  name: string;
  eat() {
    console.log("我喜欢吃肉");
  }
}
function getName(ani: object | Animal) {
  if (ani instanceof Animal) {
    return ani.name;
  }
}
```

结合接口呢？

```ts
// 定义接口
interface Animal {
    name:string;
    age:number;
    teach(subject:string):string
}

// 定义类，依赖于Animal
class Teacher implements Animal {
    name:string
    age:number
    constructor(name:string,age:number){
        this.name = name;
        this.age = age
    }
    teach(subject:string){
        return `大家好，我是${this.name}，我今年${this.age}了，我教的是${subject}`
    }
}

// 实例化
let teacher = new Teacher('张三',28);
// 判断teacher是否是Teacher类的实例
console.log(teacher instanceof Teacher)// true
```

### 自定义守护

自定义类型守护，其本质就是通过 `{形参} is {类型}` 的语法结构，来给返回布尔值的`条件函数(就像下面的isNumber)`赋予类型守卫的能力，说白了就是要定义一个函数，类似下面的例子：

```ts
function isNumber(input: number | string): input is number {
  return typeof input === "number";
}
if (isNumber(23)) {
  console.log(23);
} else {
  console.log("23");
}
```

`input is number`就是类型谓词。 谓词为 `parameterName is Type`这种形式， `parameterName`必须是来自于当前函数签名里的一个参数名。

### 类型断言

有时候你会遇到这样的情况，你会比 TypeScript 更了解某个值的详细信息（其实就是你比程序更清楚当前值的类型），通常这会发生在你清楚地知道一个实体具有比它现有类型更确切的类型。

通过类型断言这种方式可以告诉编译器，“相信我，我知道自己在干什么”。类型断言好比其他语言里的类型转换，但是不进行特殊的数据检查和解构。它没有运行时的影响，只是在编译阶段起作用。

```ts
//  写法一 使用as
let someStr: any = "田晓乐";
let len: number = (someStr as string).length;
console.log(len);

// 写法二 使用尖括号<>
let someStr1: any = "田晓乐";
let len1: number = (<string>someStr).length;
console.log(len1);
```

联合`基础类型`的时候只要符合定义类型时的其中一个就可以了。 例如：

```ts
let a: number | string;
a = 13;
a = "12";
```

上述`a`，当a被赋值成数字时，自然被断言成了`number`类型，反之亦然。

然而联合`复杂类型`，如接口时，只能获取到复杂类型的公共属性，不同的属性是会报错的，例如：

```ts
interface Bird {
  skill: string;
  song();
}
interface Fish {
  skill: string;
  swim();
}
function isBF(animal: Bird | Fish) {
  return animal.skill; // 公共属性，没问题
  return animal.song(); //Property 'song' does not exist on type 'Fish'
}
```

​  

如果我们还想访问不同的属性呢，这时就可以使用类型断言了：

```ts
interface Bird {
  skill: string;
  song();
}
interface Fish {
  skill: string;
  swim();
}

function isBF(animal: Bird | Fish) {
  // 如果有属性song局表示是Bird类型
  if ((animal as Bird).song) {
    (animal as Bird).song();
  } else {
    // 否则就是Fish类型
    (animal as Fish).swim();
  }
}

let fish = {
  skill: "游泳",
  swim() {
    console.log("我的征程是大海");
  },
};
let bird = {
  skill: "飞翔",
  song() {
    console.log("我的征程是星辰");
  },
};
isBF(fish);//我的征程是大海
isBF(bird);//我的征程是星辰

```

## 且类型(交叉类型)

就是一个变量的类型是两种类的合并，用`&`进行表示，传入的变量必须是两个类型的并集：

```ts
class Animal {
  name: string;
  eat() {}
}
class Dog {
  age: number;
  play() {}
}

function getName(ani: Dog & Animal) {
  console.log(ani.age);
}
// 必须包含全部的属性或方法
getName({
  name: "二哈",
  age: 5,
  play() {
    console.log("拆家，我在行！");
  },
  eat() {
    console.log("我喜欢吃肉");
  },
});
```

又比如

```ts
// 交叉类型
type Monkey = {
    name: string;
    age: number;
};

type Person = {
    name: string;
    hobby(): void;
};

let person: Monkey & Person; //满足的类型是Monkey和Person的并集
person = {
    name: '张三',
    age: 5,
    hobby() {
        console.log(this.name);
    }
};
```
