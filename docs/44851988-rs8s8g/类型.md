## 一、基础静态类型

其实也就是怎么以TS的方式声明一个基本类型，首先我们要知道常见的基础类型有哪些——当然是数字(number)，字符串(string)，布尔值(boolean)，null和undefined，所以在声明的时候就是`变量名:类型名`的模式：

## 代码示例

```ts
let isTrue: boolean = true; //boolean
let dahai: number = 13; // number
let xiaogou: string = "大黄"; //string
let none: null = null; // null
let nude: undefined = undefined; //undefined
```

## 二、对象类型

### 2.1、数组

声明方式有两种：`元素类型:[]`和使用数组泛型`Array<元素类型>`

```ts
let arr:number[] = [1,2,3]//数组中的元素只能是数字
// 等同于
let arr:Array<number> = [1,2,3]
```

如果数组中的元素可以是多种类型呢，那就可以使用`（类型1|类型2|类型3...）`来表示啦，例如：

```ts
// 数组中的元素可以是数字也可以是字符串
const arr3: (number | string)[] = [1, "江小白", "数组"];
// 相当于
const arr3:Array<number|string> = [1, "江小白", "数组"];
```

更复杂一点儿的数组该怎么表示呢，比如元素是对象？

```ts
// 方法1
const arr1: { name: string; age: number }[] = [
  { name: "张三", age: 13 },
  { name: "李四", age: 16 },
];
// 或者使用类型别名
type Person = { name: string; age: number };//定义一个类型别名Person
const _arr1: Person[] = [
  { name: "张三", age: 13 },
  { name: "李四", age: 16 },
];
//等同于
const _arr1_: Array<Person> = [
  { name: "张三", age: 13 },
  { name: "李四", age: 16 },
];

```

### 2.2、元组

数组还有一种表现形式是**元组（并不常用），它其实是已知元素数量和类型的数组，也就是说每个元素数据类型可以不一样，**用官网的话说：

> 表示一个已知元素数量和类型的数组，各元素的类型不必相同。 比如，你可以定义一对值分别为string和number类型的元组。

例如：

```ts
let arr: [number, string, boolean] = [1, "你好", true];
// 不能进行拓展长度，上面说的已知元素数量
arr[3] = 13
// 可以更改特定位置的元素
arr[2] = false

```

> 其实元组并不常用，一般只有在数据源是CSV格式(很老的格式)的时候才会用到

在V4.2以上的版本中解决了一个痛点——元组的元素可以不固定，因为有了`rest元素`（下方的`...boolean[]`就是rest元素），如下:

```ts
let a:[string,...boolean[],number] = ['hello',true,16];
a =  ['hello',true,false,false,16]

let b:[string,...boolean[],string] = ['world',false,true,'哈哈']
```

但需要注意的是一个元组中只能有一个`rest`元素。

标记的元组元素，就像下面这样：

```ts
type Range = [start: number, end: number];
let a:Range = [12,13];
```

上述的元素都被标记出了类型，但是一旦进行了标记，就必须所有的元素都要被标记，也就是说这样是不行的——

```ts
type Range = [start: number, number];
```

还有一种是可以这样将不同类型进行组合：

```ts

type Strings = [string, string];
type Numbers = [number, number];
// [string, string, number, number]
type StrStrNumNum = [...Strings, ...Numbers];

let d:StrStrNumNum = ['小白','大神',12,14]

```

### 2.3、函数

一般都是`函数名():返回值类型`，表示函数的有返回值而且类型确定

```ts
function sum(): number {
	return 2
}
```

### 2.4、对象

其实就是`object`类型，一般来说在对象中确定每个属性值的类型，而且属性数量也确定了。

```ts
let beautifulGirl: { name: string; age: number } = {
  name: "大美女",
  age: 18,
  sex:'女'// 会报错，因为只能有两个属性
};
console.log(beautifulGirl.age);//18
```

还有的对象是这么用的：

```ts
// object类型
function getObj(obj: object): object {
    return {
        name: '小时候的李白',
        age: 1,
        bornFrom: '李白的家',
        isFemale: false
    };
}

console.log(getObj({}));
```

## 三、其他类型

### 3.1、any

any表示变量可以**是任何类型**，不受类型约束了，例如：

```ts
let hah: any = "笑的很开心";
hah = 17;//不会报错
```

### 3.2、void

啥类型也没有，该类型的变量只能赋值`null`和`undefined`，通常用在**声明一个没有返回值的函数**的时候用到，例如：

```ts
function haha(): void {}//正确
function haha(): number {}//表示haha函数有返回值，而且返回值必须是个数字 
```

### 3.3、never

返回never的函数必须存在无法达到的终点（比如函数抛出错误，死循环等）

```ts
// 直接报错，也就没有终点咯
function getTotal(): never {
  throw new Error("报错了");
}
//死循环，肯定没有终点咯
function deadLoop(): never {
  while (true) {}
}
```

### 3.4、null和undefined

`undefined`和`null`两者各自有自己的类型分别叫做`undefined`和`null`。 和 `void`相似，它们的本身的类型用处不是很大：

```ts
let n:null = null
let u:undefined = undefined
```

默认情况下`null`和`undefined`是所有类型的子类型。 就是说你可以把 `null`和`undefined`赋值给`number`类型的变量，例如：

```ts
let nu:number = null
```

> 注意，如果要想编译不报错，必须在非严格模式下

## 四、类型断言

类型断言就是手动给变量指定一个类型，语法：

```ts
// 推荐
值 as 类型
// 或者
<string>值
```

当我们写一个变量的时候，TS会帮助我们进行类型的静态推断，如果能推断出来就不用管了，如果不能就需要类型注解了，一般这种情况发生在计算的场景中，当我们进行变量声明的时候最好还是要进行添加类型注解，例如：

```ts
// 类型断言
let lei: any = '哈哈，原来是你呀！';// 在这里lei是any类型
let len: number = (lei as string).length;
//等同于
let len:number = (<string>lei).length
// 对于编译器而言，他不知道lei具体是啥类型的，所以就不能确定其是否有length属性，但是我们自己知道呀，所以就要在这里用到类型断言，我们强制给其设置一个合理的类型。
```

在函数中一般要给参数设置类型：

```ts
let count: number = 0;
let count1: number = 19;
let sum = count + count1;//当你把鼠标放在sum上的时候，你会发现其是number类型，这就是类型推断

function getTotal(a, b) {
  return a + b;
}
const sum1 = getTotal(1, 19);

//上面的getTotal,你无法推断出sum1的类型，所以你要给变量添加注解，改成这种

function getTotal(a: number, b: number) {
  return a + b;
}
const sum1 = getTotal(1, 19);//会自动推断为number类型
```

## 五、类型推断

类型推断就是我们并不直接指定类型，让TS自己去推断类型。

类型推断一般用在两种地方：**其一变量初始化，其二用在函数的返回值中**，例如：

```ts
let age = 18;// TS会自动将age推断成number类型，所以在以后赋值的时候只能赋值number类型，否则就会报错
age = '19'// 报错
```

函数的返回值，虽然我们并没有显式指定返回值类型，但当你把鼠标放上去的时候你会发现已经推断出返回值类型了，这就是类型推断。

## 六、函数传参

### 6.1 一般传参

使用`:`直接注明类型

```ts

function getSum(a: number, b: number): number {
  return a + b;
}
const sum1 = getSum(12, 15);
```

### 6.2 参数是对象

```ts
function getSum1({ a, b }: { a: number; b: number }): number {
  return a + b;
}
const sum2 = getSum1({ a: 13, b: 14 });
```

### 6.3 参数是数组

```ts
function getSum3(countArr: number[]) {
  return countArr.reduce((pre, cur) => {
    return pre + cur;
  }, 0);
}

const sum3 = getSum3([1, 2, 3, 4, 6]);
```

> 其实TS会自动推断函数的返回值类型，所以返回值的类型可以不用显式地进行声明

## 七、type的使用

一般使用type来来自定义类型，比如：

### 7.1、自定义联合类型

```ts
type ArrTypes = string|number|boolean;
let arr:Array<ArrTypes> = ['张三',15,true]
console.log(arr);
```

定义联合类型只能访问各类型公共的属性或方法

### 7.2 定义交叉类型

定义的交叉类型在使用的时候必须是并集

```ts
// 交叉类型
type Monkey = {
    name: string;
    age: number;
};

type Person = {
    name: string;
    hobby(): void;
};

let person: Monkey & Person; //满足的类型是Monkey和Person的并集
person = {
    name: '张三',
    age: 5,
    hobby() {
        console.log(this.name);
    }
};
```
