# Vue SSR渲染

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/lo7vmi)

## 一、前端开发的三个阶段

  

1.  ### Jquery阶段
    
      
    这个阶段的前后端交互的基本模式是这样的：  
    

![图片](https://s1.ax1x.com/2020/04/05/Grl9rn.png)

-   **优点**  
    从渲染角度上讲，是在后端进行渲染的，一下子拿到了全部的DOM，有利于SEO(因为爬虫可获取的信息比较多)

-   **缺点**  
    经常操作DOM，所以性能上肯定比较低，不利于大型应用的构建

2.  ### SPA
    
      
    SPA有着优秀的用户体验，页面是由客户端js渲染出来的,这种方式是典型的客户端渲染  
    

![Gr15nA.png](https://s1.ax1x.com/2020/04/05/Gr15nA.png)

  
    从上面的结构图就知道在这种模式下客户端会和服务端有**多次的交互**（至少首屏页面的时候是这样）--第一次是拿到HTML模板，第二次是为了从服务器拿数据。  
    **SPA的优点和缺点：**

-   **优点**  
    其一由于是在客户端渲染的，所以后台的压力比较小,其二是对带宽的要求比较低（只需要拿数据就行了），因为毕竟我们拿到的只是一个空的HTML模板

-   **缺点**

1.  **不利于SEO，**因为第一次拿到的是空HTML模板，没有什么信息可以抓取，所以对于搜索引擎爬虫就是个难事

2.  **首屏加载用户体验可能不好**，因为数据要多次请求，可能会有空白界面的出现

3.  **多次请求**

3.  ### SSR渲染（服务端渲染）
    
      
    

![Gr1zBn.png](https://s1.ax1x.com/2020/04/05/Gr1zBn.png)

  
    **可以看到SSR渲染的优点是：**首屏只**发送一次请求**把后台组装好的数据和DOM组装成可以展示的HTML结构返回给前台，内容比较丰富（***但是这时候是死的界面***），然后前台只需要把界面给激活成可交互的页面就行了  
    **什么时候用?**

1.  当你的应用对首屏加载速度要求比较高的时候，因为服务端渲染是比客户端要快的

2.  还有就是如果该网站或者应用需要容易被搜到的时候。

> 什么是首屏渲染？
> 
> 就是用户第一次访问的内容就是首屏渲染(比如浏览器回车刷新)
