# .sync

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/oqpwphdnap622174)

**.sync是一个语法糖。是父组件监听子组件更新某个props的请求的****缩写语法。**

我们知道父组件通过`props`向子组件传递数据是**单向的**（不能在子组件内直接修改`props`数据！），如果我们想要修改`props`数据只能通过`$emit`抛出一个自定义事件来**通知父组件更新**`**props**`**数据。**

> **使用**`**.sync**`**是抛出的事件名必须是**`**update:xxx**`**这里的**`**xxx**`**指的是某个prop**

**用法如下**

## 代码示例

```vue
<template>
  <div class="goods_management page_container">
    <addStore :dialogVisible.sync="dialogVisible"></addStore>
		<!--相当于 -->
<!--     <addStore :dialogVisible="dialogVisible" @update:dialogVisible="dialogVisible = $event" ></addStore> -->
  </div>
</template>
<script>
import addStore from './addStore.vue'
export default {
  name: 'StoreManagement',
  components: {
    addStore
  },
  data () {
    return {
      dialogVisible: false // 名字你随便起
    }
  },
  created () {
   
  },
  methods: {
    handleAdd() {
      this.dialogVisible = true
    },
  }
}
</script>

<style lang="scss" scoped >
.goods_management {
}
</style>

```

子组件

```vue
<template>
  <el-dialog
  title="提示"
  :visible.sync="dialogVisible"
  width="30%"
  @close="$emit('update:dialogVisible', false)"
  center>
  <span>需要注意的是内容是默认不居中的</span>
  <span slot="footer" class="dialog-footer">
    <el-button @click="handleCancel">取 消</el-button>
    <el-button type="primary" @click="handleConfirm">确 定</el-button>
  </span>
</el-dialog>

</template>

<script>
export default {
  name: 'AddStore',
  props: {
    dialogVisible: {
      type: Boolean,
      default: false,
      required: true
    }
  },
  data() {
    return {

    }
  },
  methods: {
    handleCancel() {
      this.$emit('update:dialogVisible', false)
    },
    handleConfirm() {
      this.$emit('update:dialogVisible', false)
    }
  },
}
</script>

<style lang="scss" scoped>
  .basic-info{

  }
</style>
```

你会发现，其实跟传统的写法很像
