## 一、定义

图是一组由**边**连接的**节点**（或顶点）。

![image.png](/images/657deca7f4ae3333.png)

可以看到图是由一组顶点和一组边组成的， 由一条边连接在一起的顶点称为**相邻顶点** ；一个顶点的**度**是其相邻顶点的数量 ； **路径**是顶点 v1, v2, …, vk的一个连续序列 。

## 二、分类

## 2.1、有向图和无向图

图可以是无向的（边没有方向）或是有向的（有向图）。 下图是一个典型的有向图：

![image.png](/images/e5f4a35a5d86dc3e.png)

如果图中**每两个顶点间**在双向上都存在路径，则该图是**强连通的**。例如，C 和 D 是强连通的， 而 A 和 B 不是强连通的。

## 2.2、加权图和未加权图

未加权图很容易理解，即每一条边权重都一样，加权图则是图的边被赋了权重，如下图所示：

![image.png](/images/5dd511dc84eef37a.png)

## 三、图的表示

书中最常见的是用**邻接表**进行表示。**邻接表**由图中每个顶点的相邻顶 点列表所组成。存在好几种方式来表示这种数据结构。我们可以用列表（数组）、链表，甚至是 散列表或是字典来表示相邻顶点列表。下面的示意图展示了邻接表数据结构。

## 代码示例

```js
class Graphics {
        constructor(isDirected = false) {
          this.isDirected = isDirected;
          this.vertices = []; // 存储图中的所有顶点
          this.adjList = new Dictionary(); // 存储邻接表，键名是当前顶点，值是其邻接顶点组成的数组
        }
        // 向图中添加顶点
        addVertex(v) {
          if (!this.vertices.includes(v)) {
            this.vertices.push(v);
            this.adjList.set(v, []); // 刚开始其邻接节点肯定是空的呀
          }
        }
        // 添加该顶点周围的边,传入要建立关系的两个顶点
        addEdge(v, w) {
          // 如果邻接表中没有顶点v,直接往顶点列表中添加，为啥用this.adjList呢，这是因为根据addVertex就知道，如果v曾经 被添加过，其键值至少是[]，而不是null，所以可以表示
          if (!this.adjList.get(v)) {
            this.addVertex(v);
          }
          // 同上
          if (!this.adjList.get(w)) {
            this.addVertex(w);
          }
          this.adjList.get(v).push(w);
          // 判断是否是有向图
          if (this.isDirected) {
            this.adjList.get(w).push(v);
          }
        }
        // 获取顶点列表
        getVertex() {
          return this.vertices;
        }
        // 邻接表集合
        getEdges(v) {
          return this.adjList;
        }
      }

      // 字典
      class Dictionary {
        constructor() {
          this.toStrFn = toStrFn; //  确保key是字符串形式
          this.table = {}; // 初始化字典
        }
        // 向字典中添加新的数据
        set(key, value) {
          if (key !== null && key !== undefined) {
            let keyStr = this.toStrFn(key);
            this.table[keyStr] = {
              key: keyStr,
              value: value,
            };
          }
        }
        // 判断是否已经有了某个key
        hasKey(key) {
          let keyStr = this.toStrFn(key);
          // 就看key对应的value是不是有值,有值就是对象, !!对象就是true
          return !!this.table[keyStr];
        }
        // 从字典中删除一个key
        remove(key) {
          if (this.hasKey(key)) {
            let keyStr = toStrFn(key);
            delete this.table[keyStr];
            return true;
          }
          return false;
        }
        // 从字典中查找一个值
        get(key) {
          if (this.hasKey(key)) {
            return this.table[this.toStrFn(key)];
          }
          return null;
        }
        // 返回由value组成的数组
        keyValues() {
          return Object.values(this.table);
        }
        // 返回由“健”组成的数组，真正的健
        keys() {
          return this.keyValues().map((item) => item.key);
        }
        // 返回由值组成的数组,真正的值
        values() {
          return this.keyValues().map((item) => item.value);
        }
        // 清空字典
        clear() {
          this.table = {};
        }
        // 返回字典大小
        size() {
          return this.keyValues().length;
        }
        // 当前字典是否为空
        isEmpty() {
          return this.keyValues().length === 0;
        }
        // 转化为字符串
        toString() {
          if (this.isEmpty()) {
            return "";
          } else {
            return this.keyValues().join(",");
          }
        }
      }
      // 将传入的item转化为字符串形式
      function toStrFn(item) {
        if (item === null) {
          return "null";
        } else if (item === undefined) {
          return "undefined";
        } else if (item instanceof String) {
          return item;
        } else {
          return item.toString();
        }
      }

      let graphics = new Graphics();
      let nodesList = ["A", "B", "C", "D", "E", "F"];
      for (let i = 0; i < nodesList.length; i++) {
        graphics.addVertex(nodesList[i])
      }
      console.log(graphics);
      graphics.addEdge('A','C');
      graphics.addEdge('A','E');
      graphics.addEdge('B','E');
      graphics.addEdge('D','F');
      graphics.addEdge('C','D');
      console.log(graphics);
```
