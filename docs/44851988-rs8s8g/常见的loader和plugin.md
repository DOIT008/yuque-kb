# 常见的loader和plugin

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/ic7420)

## Loader

1.  styleloader：将css以style标签的形式插入到html中
2.  css-loader：将css以link的形式插入到html中
3.  babel-loader：将es6转化为ES5
4.  file-loader：用来处理各种文件的

## Plugin

1.  htmlWebpackPlugin：根据模板自动生成html代码，并自动引用响应的js和css文件
2.  cleanWebpackPlugin：每次打包都会清除上次的打包文件
3.  hotModuleReplacementPlugin：热更新模块插件
