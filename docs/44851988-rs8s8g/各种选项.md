## emits

使用`emits`选项可以很清楚的知道 当前组件抛出了哪些事件，其值可以是**字符串数组，也可以是对象**，只不过对象的形式可以配置验证函数来表明当前触发的是不是这个事件，当然也可以进行其他的处理。更多可以查看[官网emits](https://v3.cn.vuejs.org/api/options-data.html#emits)

### 举个例子

## 代码示例

```vue
// Render.vue
<template>
  <p>{{ msg }}</p>
  <button @click="changePropsData">验证Emits</button>
</template>

<script lang="ts">
import { defineComponent, ref } from "vue";
export default defineComponent({
  props: ["msg"],
  emits: {
    changeProps: (payload) => {
      // 验证函数，一旦emit事件changeProps，就会触发该验证函数,这里payload其实就是emit的payload
      console.log(payload);

      return payload ? false : true;
    },
    // 没有验证函数,一般适用于无负载的自定义事件
    changeData:null
  },
  setup(props, { emit }) {
   
    function changePropsData() {
      emit("changeProps", "现在变成了Render组件内部的数据");
      emit('changeData')
    }
    return {
      changePropsData,
    };
  },
});
</script>
```

 

```vue
// HelloWorld.vue
<template>
  <div class="container">
    <!-- 监听该事件 -->
    <Render :msg="msg" @changeProps="handleChangeProps"></Render>
  </div>
</template>
```

## watch

watch可以用来监控数据的变化，从而可以做一些事情，如果用过Vue2.x的话就知道，但是在Vue3中又有了新的变化，那就是在`setup`函数中定义的数据不能通过`Option watch`进行监控，只能通过`watch`函数，但是在`Option data`定义的数据则可以通过`Option watch`监控，例如：

### option watch

就是`watch`是一个选项。

```js
import { reactive, toRefs, defineComponent, ref, watch } from "vue";
export default defineComponent({
  props: ["msg"],
  data() {
    return {
      message: "张三是个大傻瓜",
    };
  },
  watch: {
     message(newVal, oldVal) {
      console.log(newVal, oldVal);
    },
    // message: {
    //   handler(newval, oldval) {
    //     //some code
    //   },
    //   deep:true, // 一般监控某个对象的时候要用到,当对象的属性发生变化就会触发
    //   immediate:true // 表示立即监控
    // },
  },
})
```

### watch函数

适用于监控`setup`函数中定义的数据。

#### 监控基础类型的数据

```js
const num = ref(9);
watch(num,(newVal,oldVal)=>{
  
})
```

**监控整个对象**

```js
watch(
      bookInfo,
      (newVal, oldVal) => {
        console.log(newVal, oldVal);
      }
    );
```

**监控对象中的某个属性**

```js
import { reactive, toRefs, defineComponent, ref, watch } from "vue";
setup(props, { emit }) {
    const bookInfo = reactive<Book>({
      title: "《堂吉诃德》",
      author: "塞万提斯",
      year: "1605年",
      publish: 400000000,
    });
    function changeBook() {
      bookInfo.title = "《水浒传》";
    }
  // 监控bookInfo的title属性，可以举一反三啦
    watch(
      () => bookInfo.title,
      (newVal, oldVal) => {
        console.log(newVal, oldVal);
      }
    );
    return {
      ...toRefs(bookInfo),
      changeBook,
    };
  },
   
```

#### 监控数组

要用到上述`watch`函数的第三个参数了，例如：

```js
   watch(
      () => reacData.allPlanList,// reacData.allPlanList是一个数组
      (newVal, oldVal) => {
        // 新值和旧值
      },
      {
        deep: true,// 深度监听，一般对于数组对象都要设置成true
        immediate: true,// 立即监听，如果在数据初始化的时候就触发该函数就要用到该选项，设置成true
      }
    );
```

## expose

我们经常性的在通过 [$refs](https://v3.cn.vuejs.org/api/instance-properties.html#refs)、[$parent](https://v3.cn.vuejs.org/api/instance-properties.html#parent) 或 [$root](https://v3.cn.vuejs.org/api/instance-properties.html#root) 访问到的公共实例与模板使用的组件内部实例是一样的。`expose` 选项将限制公共实例可以访问的 property。更多参考[官网expose](https://v3.cn.vuejs.org/api/options-data.html#expose)。

> 也就是说expose选项能够限制那些属性或方法被暴露了出来，以便被子组件，父组件访问到

```ts
export default {
  // increment 将被暴露，
  // 但 count 只能被内部访问
  expose: ['increment'],

  data() {
    return {
      count: 0
    }
  },

  methods: {
    increment() {
      this.count++
    }
  }
}
```

## 实例方法

1.  $emit（常用）：常用于抛出自定义事件
2.  $nextTick（常用）：当页面DOM更新的时候，获取更新数据后的DOM时会使用
3.  $watch：监控
4.  $forceUpdate：迫使组件实例重新渲染。**注意它仅仅影响实例本身和插入插槽内容的子组件，而不是所有子组件。**

## 实例属性

1.  $data：数据对象
2.  $prop(传过来的数据对象)
3.  $el：组件实例正在使用的根 DOM 元素。
4.  $options：用于当前组件实例的初始化选项。当你需要在选项中包含自定义 property 时会有用处
5.  $parent：父组件
6.  $root：根组件
7.  $slot：访问插槽分发的内容
8.  $refs：一个对象，持有注册过 [refattribute](https://v3.cn.vuejs.org/guide/component-template-refs.html) 的所有 DOM 元素和组件实例。
9.  $attrs：包含了父作用域中不作为组件 [props](https://v3.cn.vuejs.org/api/options-data.html#props) 或[自定义事件](https://v3.cn.vuejs.org/api/options-data.html#emits)的 attribute 绑定和事件。当一个组件没有声明任何 prop 时，这里会包含所有父作用域的绑定，并且可以通过 v-bind="$attrs" 传入内部组件——这在创建高阶的组件时会非常有用。

更多实例参考[官网](https://v3.cn.vuejs.org/api/instance-properties.html)
