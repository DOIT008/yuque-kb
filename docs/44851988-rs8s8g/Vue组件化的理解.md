# Vue组件化的理解

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/wnt8yd)

## 背景与思路

1.  组件是**独立和可复用**的代码组织单元。组件系统是 Vue 核心特性之一，它使开发者使用小型、 独立和通常可复用的组件构建大型应用；
2.  组件化开发能大幅提**高应用开发效率、测试性、复用性**等；
3.  组件使用按分类有：页面组件、业务组件、通用组件；
4.  vue 的组件是基于配置的，我们通常编写的组件是组件配置而非组件，框架后续会生成其构造函数，它们基于 VueComponent，扩展于 Vue；
5.  vue 中常见组件化技术有：属性 prop，自定义事件，插槽等，它们主要用于组件通信、扩展等；
6.  合理的划分组件（比如对于一个页面，我们只更新一小部分，那么我们就可以把这个“频繁改变”的部分划分出来成一个组件），有助于提升应用性能；
7.  组件应该是高内聚（功能比较单一）、低耦合(不依赖于其他的组件或者东西)的；
8.  遵循单向数据流的原则（这个组件只负责展示，不负责数据的改变，如果硬要改变使用自定义事件即可，当然也包括Vuex）。
