其实本质上枚举类型就是一个映射集合(对象)，用关键字`enum`进行声明，例如：

## 类型

### 没有初始化值

每隔枚举成员都没有声明枚举值，其枚举值是从0开始的数字，你会发现映射关系是一种双向的

> 一般涉及到常量的枚举类型前面要加一个const

## 代码示例

```ts
const enum Animal {
  DOG,
  CAT,
  MOUSE,
  CHICKEN,
  PIG,
}
console.log(Animal)
// {
//   '0': 'DOG',
//   '1': 'CAT',
//   '2': 'MOUSE',
//   '3': 'CHICKEN',
//   '4': 'PIG',
//   DOG: 0,
//   CAT: 1,
//   MOUSE: 2,
//   CHICKEN: 3,
//   PIG: 4
// }
```

### 部分有初始化值

这种情况其他枚举值会从第一个枚举成员的枚举值顺延，例如：

```ts
enum Animal1 {
  DOG = 8,
  CAT,
  CHICKEN,
  PIG,
}
console.log(Animal.CAT)//9
console.log(Animal.CHICKEN)//10
console.log(Animal.PIG)//11
```

又例如

```ts
enum Nums {
	one=10,
  two,
  three=20,
  four
}

// Nums.two => 11
// Nums.four => 21

```

### 全部设置枚举值

这个就很好理解了

```ts
enum Animal2 {
  DOG = "dog",
  CAT = "cat",
  MOUSE = "mouse",
}
console.log(Animal2.DOG)//dog
```

### 计算的枚举值

```ts
const n = 10;
enum Nums1 {
    one = n,
    two = one * 3// 因为此时one已经是10了
}
console.log(Nums1);// {10: 'one', 30: 'two', one: 10, two: 30}
```

### 字符串枚举

和数字枚举不一样的是，字符串枚举没有反向映射，举个例子：

```ts
enum StrIndex {
    one = 'one',
    two = 'two1'
}

console.log(StrIndex);// {one: 'one', two: 'two1'}
```

## 按声明方式分

### 普通枚举

最常见的枚举方式

```ts
enum NumEnum { a, b c }
```

### const枚举

使用 `const` 修饰符来强调当前枚举类型，该类型的枚举不会生成反向映射（你懂的）：

```ts
// 修饰符 + 关键词 + 枚举名称
const enum NumEnum { a, b, c }
// 上述声明了一个常量枚举，并且内部的数据均为只读常量
// const 枚举不会生成 lookup table，并且运行时不可访问当前枚举对象，只允许访问枚举成员的值；
const OBJ = NumEnum => Error，运行时不存在
function returnNumber (obj: { a: number }): number {
  return obj.a
}
returnNumber(NumEnum) => Error，运行时不存在
const A = NumEnum['0'] => Error，没有生成反向映射，所以不存在该属性
const B = NumEnum['b'] => 0/* b */
// 基于 const 枚举的特点，如果你只是为了生成一组常量并且只需要获取某一个常量
// 从性能方面考虑，const 枚举是首选；
// 当然如果你在 tsconfig.json 中指定下面选项
"compilerOptions": {
  // 保留 const 和 enum 声明该项为 true
  "preserveConstEnums": true
}
// 或者在命令行中添加了 --preserveConstEnums 指令，均会让当前 const 枚举转变为普通枚举
// 即会生成反向映射表；在实际开发中，一般情况你可能需要禁止掉该项，除非想要用于调试；
```

另外，不能访问映射本身只能方位映射成员的值：

```ts
console.log(NumEnum)// NumEnum is not defined
```

### 外部枚举(一般也不用)

即使用`declare`关键词来声明一个枚举，这种声明枚举的方式比较特别，使用的时候需要非常谨慎，该枚举类型不会生成反向映射：

```ts
declare enum TomCat {
    eye,
    leg,
    mouse
}
console.log(TomCat); //TomCat is not defined
console.log(TomCat.eye); //TomCat is not defined
```

### 外部常量枚举（一般不用）

使用`declare`和`const`关键词联合声明的枚举类型，这个枚举类型和 `const` 枚举类型并没有什么区别，只是会提示是否有枚举命名冲突和成员冲突，该枚举类型不会生成反向映射：

```ts
// 声明语 + 修饰符 + 关键词 + 枚举名称
declare const enum ChineseZodiac {
  rat = 1,
  cattle,
  tiger,
  rabbit,
  dragon
}
ChineseZodiac.dragon => 5/* dragon */
```

## 应用

### 用在函数中

枚举类型可以像接口那样去约束函数的参数，那么此时参数只能传枚举类型的枚举值，而且还不能直接传值进去，例如：

```ts
enum Animal2 {
  DOG = "dog",
  CAT = "cat",
  MOUSE = "mouse",
}

function sayAnimalName(animal: Animal2) {
  console.log(animal);
}
sayAnimalName(Animal2.CAT); //只能这样传，传的是枚举值！
sayAnimalName("cat"); //报错 Argument of type '"cat"' is not assignable to parameter of type 'Animal2'
```

### 用在接口中

如果接口某个属性类型设置成了某个枚举值，那么在使用该接口的时候，该属性的值只能有两种选择：一种直接是对应枚举成员的枚举值，一种是对应枚举成员的数据类型的其他值，反正不能是其他的数据类型！例如：

```ts
const enum CL {
  ONE,
  TWO,
  THREE,
}

interface Nums {
  first: CL.ONE;//first的类型设置成了ONE的枚举值
}
// 使用该接口去约束变量,设置成对应枚举成员ONE的枚举值
let nums: Nums = {
  first: CL.ONE,
};
console.log(nums);//{first:0}

// 设置成同类型的值，因为美剧成员first的枚举值是0，所以在这里可以设置成9
let nums: Nums = {
  first: 9,
};
console.log(nums);//{first:9}

// 不能设置成其他类型的值
let nums: Nums = {
  first: '哈喽',
};// 报错
```

当然枚举类型还有其他用途，在此就不再一一列举了，我想只要是涉及到一一对应关系到可能都会出现他的身影吧！
