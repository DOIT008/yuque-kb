分为三种：默认布局、自定义布局和

## 一、默认布局

默认布局是在顶层起作用的，写法也比较固定——在项目的根目录下创建`layouts`文件夹并在该文件夹下创建`default.vue`文件：

## 代码示例

```latex
-|layouts/
---|default.vue
```

 

```vue
<template>
  <div class="default-layout">
    <!-- 这里是默认布局页,default.vue -->
    <slot />
  </div>
</template>

```

默认布局不需要在每个页面额外的配置，即可生效

## 二、自定义布局

这种布局系统也是在`layouts`文件夹 下创建`.vue`文件，不过名字可以随便起了，我们创建一个：

```vue
<template>
  <div class="default-layout">
    <!-- 这里是默认布局页,default.vue -->
    <slot />
  </div>
</template>
```

在你需要这个布局的页面中添加属性`layout`:

```vue
<template>
  <div>
    <h3>这里是child2页面</h3>
  </div>
</template>

<script>
export default {
  layout: 'side',// 名字和布局文件名一致
}
</script>

<style lang="scss" scoped></style>

```

## 三、使用NuxtLayout

上述两种方式相对而言不是太灵活，但是使用`NuxtLayout`这里就是你的世界了，结合`slots`，同时你要在所用的组件中设置属性`layout:false`,还是上面的例子

​  

```vue
<template>
  <!-- name属性表示使用的是side.vue作为布局模板,也可以有多个NuxtLayout只要属性name不一样 -->
  <NuxtLayout name="side">
    <template v-slot:title>
      <div>
        <h3>这里是child2页面,title内容</h3>
      </div>
    </template>
    <template v-slot:footer>
      <div>
        <h3>这里是child2页面,footer内容</h3>
      </div>
    </template>
    <template v-slot:default>
      <div>
        <h3>这里是child2页面,default内容</h3>
      </div>
    </template>
  </NuxtLayout>
</template>

<script>
export default {
  layout: false,
}
</script>

<style lang="scss" scoped></style>

```

对应`side.vue`

```vue
<template>
  <div class="side-layout">
    这里是默认布局页,side.vue
    <slot />
    <slot name="title"></slot>
    <slot name="footer"></slot>
  </div>
</template>

```
