# 内置对象

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/qehmsm)

## 一、JS内置对象

JS内部有很多定义好的**内置对象**，在TS中也可以直接当做已知的数据类型进行使用：

## 代码示例

```ts
let b: Boolean = new Boolean(true);
let n: Number = new Number(10);
let s: String = new String('哈喽');
let reg: RegExp = /d/;
let d: Date = new Date('2021-12-11');
let e: Error = new Error('哈哈，错了吧！');

// 但是不能这样使用，以Number类型为例：
let n1: number = new Number(10);
let n1: Number = 10;
console.log(b, n, s);
// 因为此时你会发现上述的b，n，s...都是对象

```

## 二、BOM对象和DOM对象

JS中的BOM对象和DOM对象在TS中可以直接使用，例如：

```ts
const con: HTMLElement = document.getElementById('container');
const con1: HTMLDivElement = document.querySelector('div');
```
