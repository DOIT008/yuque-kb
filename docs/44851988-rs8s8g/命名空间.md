## 定义

主要用于组织代码，**避免命名冲突，**使用关键字`namespace`，其基本格式是：

## 代码示例

```ts
namespace 空间名 {
// 你的TS代码
}
```

例如：

```ts
// index.ts
namespace A {
  // 如果你想暴露出来让外部使用，你就要使用export
 	export let a = 1
}
  
console.log(A.a)//1
```

## 命名空间+模块化

其实我更想说的是如何将命名空间和模块化结合起来，毕竟将来的代码都是分模块话的，其实也很简单，你只需将该命名空间暴露出去就行了，也是使用`export`。例如：

```ts
// 16.ts
使用export将空间A暴露出来
export namespace A {
  interface Animal {
    name: string;
    eat(): void;
  }

  export class Dog implements Animal {
    name: string;
    constructor(name: string) {
      this.name = name;
    }
    eat(): void {
      console.log(this.name + "在吃骨头");
    }
  }

  export class Cat implements Animal {
    name: string;
    constructor(name: string) {
      this.name = name;
    }
    eat(): void {
      console.log(this.name + "在吃老鼠");
    }
  }
}
  

// 同理
export namespace B {
  interface ConfigFn {
    (a: number, b: number): number;
  }
  let add: ConfigFn;
  add = function (a: number, b: number): number {
    return a + b;
  };
  export let getSum = add;
}
```

模块化引入

```ts
// 17.ts
import { A, B } from "./16";
let cat = new A.Cat("中华狸花猫");
cat.eat(); //中华狸花猫在吃老鼠

console.log(B.getSum(12, 13)); //25

```

是不是很熟悉呢，其实简单来说你就把命名空间当作一个模块就行了

> 从上面也可以看出，其实在一个文件中也可以有多个命名空间

## 子命名空间

其实想想就知道，就是命名空间里套命名空间，使用方法和命名空间差不多（不过估计不常用吧），例如：

```ts
// 16.ts
export namespace Father {
  export namespace Son {
    export const a = 15;
    export const b = 18;
    export class Person {
      name: string;
      constructor() {
        this.name = "张三";
      }
      play(): void {
        console.log(this.name + "喜欢打篮球");
      }
    }
  }
}
```

引入和使用

```ts
let person = new Father.Son.Person();
person.play(); //张三喜欢打蓝球
```
