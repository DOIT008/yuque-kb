# 二分法查找

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/gybwtn)

## 原理

对于一组有序数据，先从中间找，如果中间的比实际我们要找的值要大，那就从该猜测值的左侧或右侧数据范围中找到其中间位置的值，作为新的猜测值，以此类推，直到找到该值为止。

## 复杂度

O(log(n))

## 实现

## 代码示例

```js
const NUM_ARR = [1, 2, 6, 8, 12, 45, 89, 129, 872, 900];
function findIndex(num) {
  let subIndex = 0;// 初始
  let preIndex = NUM_ARR.length - 1;
  while (subIndex <= preIndex) {
    // 因为midIndex和guess是要随着循环变化的，所以要放在循环中才行
    let midIndex = Math.round((subIndex + preIndex) / 2);
    let guess = NUM_ARR[midIndex];
    if (guess > num) {
      // 对于上面的数组，如果猜测的值比实际我们要找的值要大，那么就从该猜测值的左侧下标作为preIndex，所以要-1
      preIndex = midIndex - 1;
    } else if (guess < num) {
         // 对于上面的数组，如果猜测的值比实际我们要找的值要小，那么就从该猜测值的右侧下标作为subIndex，所以要+1
      subIndex = midIndex + 1;
    } else if (guess === num) {
      return midIndex;
    } else {
      console.log('未找到匹配项');
    }
  }
}

console.log(findIndex(2));

```
