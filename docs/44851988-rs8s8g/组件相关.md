## 非Prop的属性

什么叫“非Prop的属性”，说白了就是写在组件标签上的属性并没有在组件内部通过`props`接收，例如Render组件：

## 代码示例

```vue
// HelloWorld.Vue
 <template>
		<Render
        class="render-compo"
        id="renderCompo"
        data-source="hello"
        :msg="msg"
        @changeProps="handleChangeProps"
        ></Render>

</template>
```

上面的属性`class`、`id`、`data-source`都是非prop属性，因为他们并没有在render组件内部使用`props`接收：

```vue
// Render.vue
<template>
// 根节点
  <div>
    <p>
      {{ author }}在{{ year }}写了{{ title }}，迄今为止全球销量达{{
        publish
      }}册！
    </p>
    <p>{{ msg }}</p>
    <p>{{ message }}</p>
    <button @click="changePropsData">验证Emits</button>
    <button @click="changeBook">验证Option Watch</button>
    <button @click="message = '李四是个大傻瓜'">
      验证Option OptionData Watch
    </button>
  </div>
</template>

<script lang="ts">
  import { reactive, toRefs, defineComponent, ref, watch, onMounted } from "vue";
  export default defineComponent({
    props: ["msg"],
  }),
</script>
```

## 两种情况

### 组件有根节点

就是说组件`template`标签内部有一个`div`包裹着全部的内容，这种情况，上述的非prop属性会被加到根节点上：

![image.png](/images/626a0fd4c528de80.png)

​  

### 没有根节点

和上述相比没有`div`这个包裹元素，上述的非`prop`属性不会进行继承：

![image.png](/images/81d208566ae9d5e0.png)

## 禁用attribute继承

如果你**不**希望组件的根元素继承 attribute，你可以在组件的选项中设置 inheritAttrs: false。例如：禁用 attribute 继承的常**见情况是需要将 attribute 应用于根节点之外的其他元素**。

```js
<script lang="ts">
  import { reactive, toRefs, defineComponent, ref, watch, onMounted } from "vue";
  export default defineComponent({
    props: ["msg"],
    inheritAttrs:false
  }),
</script>
```

![image.png](/images/7e3d7e365b1bcaa1.png)

从上面可以看到，虽然有根节点，但是却没继承属性。

### 给其他元素

可以通过给某些组件或者DOM标签设置`v-bind="$attrs"`可以将上述的属性添加到对应的组件/标签上：

```vue
<template>
  <p>
    {{ author }}在{{ year }}写了{{ title }}，迄今为止全球销量达{{ publish }}册！
  </p>
  <p>{{ msg }}</p>
  <p>{{ message }}</p>

  <button v-bind="$attrs" @click="changePropsData">验证Emits</button>
  <button v-bind="$attrs" @click="changeBook">验证Option Watch</button>

  <button @click="message = '李四是个大傻瓜'">
    验证Option OptionData Watch
  </button>
</template>
```

## 访问这些属性

可以在组件的生命周期`created`中通过`$attrs`进行访问，是一个对象：

```js
<script lang="ts">
  import { reactive, toRefs, defineComponent, ref, watch, onMounted } from "vue";
  export default defineComponent({
    props: ["msg"],
    inheritAttrs:false,
    created(){
    	console.log(this.$attrs)
    },
  }),
</script>
```

> CompositionAPI中没有this对象，所以访问不了
