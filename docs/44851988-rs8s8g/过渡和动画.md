## 过渡

所谓“过渡”，就是元素/组件从一种状态以什么样的方式到达另一种状态，和Vue2.x一样，在Vue3中我们也可以使用内置组件`<transition>`来为元素/组件的进入或离开设置过渡方式：

### 举个例子

## 代码示例

```vue
<template>
  <button @click="toggleShowInfo">改变provide的数据</button>
  <transition name="fade1">
    <p v-show="showInfo">我叫{{ user.firstName }} {{ user.lastName }}</p>
  </transition>
</template>

<script>
import { ref, computed, reactive, toRefs } from "vue";
export default {
  name: "son",
  setup(props, { emit }) {
    const sonData = reactive({
      user: {
        firstName: "John",
        lastName: "Smith",
      },
      showInfo: true,
    });
    function toggleShowInfo() {
      sonData.showInfo = !sonData.showInfo;
    }
    return {
      ...toRefs(sonData),
      toggleShowInfo,
    };
  },
};
</script>

<style lang="scss" scoped>
// 定义元素/组件显示前的开始状态，或者离开后要达到的最终状态
.fade1-enter-from,
.fade1-leave-to {
  opacity: 0;
}
// 定义离开过渡/进入过渡的生效状态，说白了就是定义你怎么进入的，怎么离开的（离开过渡的过程时间，延迟和曲线函数）
.fade1-enter-active,
.fade1-leave-active {
  transition: opacity 1s ease;
}

// 定义元素进入过渡的结束状态/离开过渡的开始状态（说白了就是定义元素/组件显示时的最终状态，隐藏时的开始状态）
.fade1-enter-to,
.fade1-leave-from {
  opacity: 1;
}
</style>

```

当我们点击按钮的时候，你会发现`p`元素是有过渡动画的，这样对用户来说是一种美，但是上述`fade1-enter-from`,`.fade1-leave-to`,`fade1-enter-active`,`fade1-leave-active`等这些类名是咋来的呢，其实他们衍生于这些类名：

1.  v-enter-from：定义进入过渡的开始状态。在元素被插入之前生效，在元素被插入之后的下一帧移除。
2.  v-enter-active：定义进入过渡生效时的状态。在整个进入过渡的阶段中应用，在元素被插入之前生效，在过渡/动画完成之后移除。这个类可以被用来定义进入过渡的过程时间，延迟和曲线函数。
3.  v-enter-to：定义进入过渡的结束状态。在元素被插入之后下一帧生效 (与此同时 v-enter-from 被移除)，在过渡/动画完成之后移除。
4.  v-leave-from：定义离开过渡的开始状态。在离开过渡被触发时立刻生效，下一帧被移除。
5.  v-leave-active：定义离开过渡生效时的状态。在整个离开过渡的阶段中应用，在离开过渡被触发时立刻生效，在过渡/动画完成之后移除。这个类可以被用来定义离开过渡的过程时间，延迟和曲线函数。
6.  v-leave-to：离开过渡的结束状态。在离开过渡被触发之后下一帧生效 (与此同时 v-leave-from 被删除)，在过渡/动画完成之后移除。

在进入/离开过渡的过程中，`p`元素的类名会在上述几个类名中进行变化，只不过就像官网说的那样，由于

> 对于这些在过渡中切换的类名来说，如果你使用一个没有名字的 &lt;transition&gt;，则 v- 是这些class名的默认前缀。如果你使用了 &lt;transition name="my-transition"&gt;，那么 v-enter-from会替换为 my-transition-enter-from。
> 
> **v-enter-active** **和** **v-leave-active** **可以控制进入/离开过渡的不同的缓和曲线，**

我们在`transition`标签中使用了`name=fade1`，所以这些类名的前缀都便成了`fade1`

### 条件显示

针对上述的例子，如果我们使用`v-if`，`v-else-if`，`v-else`这些命令来控制不同的组件，你会 发现也是可以的：

```vue
<template>
  <button @click="toggleShowInfo">切换1</button>
  <transition name="fade1">
    <p v-if="showInfo === 1">我叫{{ user.firstName }} {{ user.lastName }}</p>
    <p v-else-if="showInfo === 2">我叫张三</p>
    <p v-else>我叫李四</p>
  </transition>
</template>
```

### 列表渲染

如果对于整体的列表渲染，我们当然可以用`transition`组件，但是如果我们对某个已存在的列表进行增、删、改呢，这时候使用`transition`组件就不行了，但是我们可以使用组件`<transition-group>`。

先看一下该组件的**特点**吧：

-   默认情况下，它不会渲染一个元素的包裹器，但是你可以指定一个元素并以 tag `attribute` 进行渲染(比如tag= "div" 表示将来会用 div元素来整体包裹这些列表元素)。
-   [过渡模式](https://v3.cn.vuejs.org/guide/transitions-enterleave#%E8%BF%87%E6%B8%A1%E6%A8%A1%E5%BC%8F)不可用，因为我们不再相互切换特有的元素。
-   内部元素**总是需要**提供唯一的 `key` attribute 值。
-   CSS 过渡的类将会应用在内部的元素中，而不是这个组/容器本身。

例如：

```vue
<div id="list-demo">
  <button @click="add">Add</button>
  <button @click="remove">Remove</button>
  <transition-group name="list" tag="p">
    <span v-for="item in items" :key="item" class="list-item">
      {{ item }}
    </span>
  </transition-group>
</div>
<style lang= "scss" >
  .list-item {
    display: inline-block;
    margin-right: 10px;
  }
  .list-enter-active,
  .list-leave-active {
    transition: all 1s ease;
  }
  .list-enter-from,
  .list-leave-to {
    opacity: 0;
    transform: translateY(30px);
  }  
<style>
```

你会发现这些类名是被加到了`span`元素上，并且在span元素列表的外部有一个`p`元素包裹。

### 状态过渡

与其说状态过渡，还不如说是数据变化的过渡，比如一个数字从0到100中间的过渡，可能需要用到`gsap`这个插件，具体可看官网[状态过渡](https://v3.cn.vuejs.org/guide/transitions-state.html#%E7%8A%B6%E6%80%81%E5%8A%A8%E7%94%BB%E4%B8%8E%E4%BE%A6%E5%90%AC%E5%99%A8)
