Vue中除了有内置的一些指令，我们也可以自定义指令来实现一些特定的共功能，Vue3中的自定义指令基本上和Vue2.x的差不多，但还是有些许差别的

## 全局指令

一般在`main.js`中定义，然后全局都能用，例如：

## 代码示例

```js
import { createApp } from "vue"; // 引入createApp函数
import App from "./App.vue"; // 其实其实就是一个对象
import "./index.css";
import store from "./store/index.js";
// 执行挂载进行实例化

const app = createApp(App);
//指令
app.directive("focus", {
  // 钩子
  mounted(el, binding,vnode,prevNnode) {
    // 在绑定元素的父组件被挂载后调用。最常用
    el.focus();
  },
});
app.use(store);
app.mount("#app");
```

## 局部指令

顾名思义就是在组件内定义的指令，该指令只能在本组件内使用，写法和Vue2.x 的写法差不多：

```js
export default defineComponent({
  props: ["msg"],
  // 在directive选项中定义指令v-focus
  directives: {
    focus: {
      mounted(el, binding) {
        el.focus();
      },
    },
  },
})
```

## 使用

在使用钩子的时候一般我们要在指令名（如上面的`focus`）前加前缀`v-`，变成`v-指令名`。

### 钩子

指令会有一些钩子：

1.  created：在绑定元素的 attribute 或事件监听器被应用之前调用。在指令需要附加须要在普通的 v-on 事件监听器前调用的事件监听器时，这很有用。
2.  beforeMount：当指令第一次绑定到元素并且在挂载父组件之前调用。
3.  **mounted：在绑定元素的父组件被挂载后调用（常用）。**
4.  beforeUpdate：在更新包含组件的 VNode 之前调用。
5.  updated：在包含组件的 VNode **及其子组件的 VNode** 更新后调用。
6.  beforeUnmount：在卸载绑定元素的父组件之前调用
7.  unmounted：当指令与元素解除绑定且父组件已卸载时，只调用一次。

一般最常用的还是`mounted`钩子。

### 钩子参数

每个钩子都有四个参数`el`、`binding`、`vnode`、`prevNode`

-   el：当前指令绑定的DOM。
-   binding：一个对象，里面包含关于指令的一些信息：

-   instance：使用指令的组件实例。
-   value：传递给指令的值。例如，在 v-my-directive="1 + 1" 中，该值为 2，当然绑定的值也可能是一个对象，此时value就是对象。
-   arg：参数传递给指令 (如果有)。例如在 v-my-directive:foo 中，arg 为 "foo"。
-   modifiers：包含修饰符 (如果有) 的对象。例如在 v-my-directive.foo.bar 中，修饰符对象为 {foo: true，bar: true}。
-   dir：一个对象，在注册指令时作为参数传递。

-   vnode：当前的虚拟节点。
-   prevNode：上一个虚拟节点，仅在 `beforeUpdate` 和 `updated` 钩子中可用。

## 动态指令参数

指令的参数可以是动态的。例如，在 `v-mydirective:[argument]="value"` 中，`argument` 参数可以根据组件实例数据进行更新！这使得自定义指令可以在应用中被灵活使用。

> 这里的argument可以是实例中的数据，当然也也可以是写死的

还是以上述的`v-focus`指令为例：

```vue

<template>
  <input type="text" v-focus:[direction]="300" />
</template>

<script>
  export default defineComponent({
    props: ["msg"],
    // 在directive选项中定义指令v-focus
    directives: {
      focus: {
        mounted(el, binding) {
          el.focus();
          console.log(binding.args)//right
        },
      },
    },
    setup(props, { emit }) {
      // 响应式数据
      const direction = ref("right");
      return {
        direction,
      };
  	},
  })
</script>
```

## 一些常用的指令

### 1\. v-slot

插槽相关，跟Vue2.x差不多，通常可以用在剧名插槽和作用域插槽，例如：

```vue
<!-- 具名插槽 -->
<base-layout>
  <template v-slot:header>
    Header content
  </template>

  <template v-slot:default>
    Default slot content
  </template>

  <template v-slot:footer>
    Footer content
  </template>
</base-layout>

<!-- 接收 prop 的具名插槽 -->
<infinite-scroll>
  <template v-slot:item="slotProps">
    <div class="item">
      {{ slotProps.item.text }}
    </div>
  </template>
</infinite-scroll>

<!-- 接收 prop 的默认插槽，使用了解构 -->
<mouse-position v-slot="{ x, y }">
  Mouse position: {{ x }}, {{ y }}
</mouse-position>
```

### 2\. v-cloak

直到数据准备完毕，否则不显示（防止初始化页面的时候出现花括号），一般和CSS一起使用

```vue
<div v-cloak>
  {{ message }}
</div>
<style scoped >
  [v-cloak] {
    display: none;
  }
</style>

```

### 3\. v-once

只渲染元素和组件**一次**。随后的重新渲染，元素/组件及其所有的子节点将被视为静态内容并跳过。这可以用于优化更新性能。

```vue
<!-- 单个元素 -->
<span v-once>This will never change: {{msg}}</span>
<!-- 有子元素 -->
<div v-once>
  <h1>comment</h1>
  <p>{{msg}}</p>
</div>
<!-- 组件 -->
<my-component v-once :comment="msg"></my-component>
<!-- `v-for` 指令 -->
<ul>
  <li v-for="i in list" v-once>{{i}}</li>
</ul>
```

### 4\. v-memo

> Vue3.2+上新增

记住一个模板的子树。元素和组件上都可以使用。该指令**接收一个固定长度的数组**作为依赖值进行记忆比对。如果数组中的每个值都和上次渲染的时候相同，则整个该子树的更新会被跳过。例如：

```vue
<div v-memo="[valueA, valueB]">
  ...
</div>
```

不过一般情况下用不到，只有在极端的情况下才会用到，比如在渲染很长（长度大于1000）的列表的时候：

```vue
<div v-for="item in list" :key="item.id" v-memo="[item.id === selected]">
  <p>ID: {{ item.id }} - selected: {{ item.id === selected }}</p>
  <p>...more child nodes</p>
</div>
```

当组件的 `selected` 状态发生变化时，即使绝大多数 `item` 都没有发生任何变化，大量的 `VNode` 仍将被创建。此处使用的 `v-memo` 本质上代表着“仅在 `item` 从未选中变为选中时更新它，反之亦然”。这允许每个未受影响的 item 重用之前的 `VNode`，并完全跳过差异比较。注意，我们不需要把 `item.id` 包含在记忆依赖数组里面，因为 Vue 可以自动从 `item` 的 `:key` 中把它推断出来。

### 5\. v-text

```vue
<span v-text="msg"></span>
<!-- 等价于 -->
<span>{{msg}}</span>
```

> 当然还有其他内置的指令，比如：`v-model`，`v-show`,`v-bind`,`v-text`,`v-html(不常用)`等，只不过这些指令很常用就不单独解释了
