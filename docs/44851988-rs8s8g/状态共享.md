## 背景与思路

使用useState，创建响应式且服务端有好的垮组件状态共享能力，其本质 是ref替换；

## 代码示例

```ts
useState(key:string,init:()=>T):ref<T>
key:唯一键用于去重
init:提供初始的函数
 
const counter = useState('counter',()=>1)
```
