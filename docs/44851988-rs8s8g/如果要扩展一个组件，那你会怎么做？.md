# 如果要扩展一个组件，那你会怎么做？

> 来源：语雀「前端」 · [查看原文](https://www.yuque.com/alipayqxigqpgusn/rs8s8g/oxhnn5)

常用的方法有三个：mixins和extends（逻辑扩展），还有slot（内容扩展）

## mixins（混入）

## 代码示例

```js
export default {
	data(){
  	return {
    	// ....
    }
  },
  methods:{
  	// ...
  },
  filters:{
  	// ...
  }
  // 其他选项..
}
```

混入又分为全局混入 `Vue.mixin(mixin)` 和局部混入：

```vue
{
	mixins:[mix1，mix2,...]// 可以混入多个
}
```

> 通常我们可以新建一个js文件来存放这些混入

### 特点

1.  混入中data选项中的同名数据比组件本身的数据优先级要高
2.  钩子函数将混合为一个数组，**混入对象的钩子将在组件自身钩子之前调用**
3.  **值为对象的选项**，例如 methods, components 和 directives，将被混合为同一个对象。两个对象键名冲突时，取组件**对象的键值对**。

> 但是这个混入带来了一个缺点就是对于混入的东西我们必须很小心，因为很可能会和当前组件内部的数据，包括方法等。

## extends （扩展）

其实和mixin很想，只不过还是有区别的：

```js
const extends1 = {
	methods:{
		doIt(){
			// ...
		}
	}
} 

// 某个组件
// import extends1 from 'path'

{
	extends:extends1
}
```

### 特点

1.  `extends` 只能扩展单个对象， `mixins` 可以是多个（数组嘛）
2.  优先级比 `mixins` 高，和 `mixins` 起冲突就会覆盖混入的内容

## slot（内容分发）

默认插槽，具名插槽（想要某些东西插入到具体的位置），作用域插槽（想把子组件内部的数据展示到父组件）...

## Vue.extend

Vue.extend使用基础 Vue 构造器，创建一个“子类”。参数是一个包含组件选项的对象。很明显不能作为扩展嘛！

```js
// Vue.extend
// 创建构造器
var Profile = Vue.extend({
  template: '<p>{{firstName}} {{lastName}} aka {{alias}}</p>',
  data: function () {
    return {
      firstName: 'Walter',
      lastName: 'White',
      alias: 'Heisenberg'
    }
  }
})
// 创建 Profile 实例，并挂载到一个元素上。
new Profile().$mount('#mount-point')
```
